# Hot Post — 2026-11-11 21:30 JST (night / 考察・逆張り)

## 🤖 AIが見つけた「脆弱性」は9割、修正されたのは0.6% — Glasswing台帳の逆張り監査

**▶ 一言要約**: 7ヶ月で37,966件発見・修正217件(+15)。Anthropicの脆弱性発見マシンは「発見器」であって「修正器」ではない。

**詳細** (VulnCheck Nov 9, HN 410pts/198c):
- **442 CVEs** = 今年の全93,450 CVEの**0.5%**。Wild exploitationは**2件**(0.45%)。プロジェクト立ち上げ時の「侵害されたら致命的」ナラティブと実データの差が最大の論点。
- 台帳の9-11月差分: findings **+11,813** に対して fixes **+15**、duplicate **2→1,670**、withdrawn **245→419**。同じ期間に claimed true-positive rate は 91.4%→**94.2% に上昇** — duplicate/withdrawn を分母から外している疑い。
- 10月開始の OSS Scanner は「fully model-generated, without human review」で report を Maintainer に直接送付。triage ボトルネックを Anthropic から Maintainer に移しただけ、というのが VulnCheck の評価。
- curl 実測: 公開34件中**19件(55.9%)が「脆弱性でない」**、confirmed low 6件、保留9件。9月には Claude 判定 91.5% critical/high に対し Maintainer 判定は 51.3%。severity inflation が二重に起きている。
- HN の対抗筋: [ameliaquining] Claude は修正パッチを出せるが出さない — Maintainer が AI パッチを未经由で merge する信頼がなく、レビュー工数は自前で作るのと同等。

| 指標 | Sep 8 | Nov 2 | Δ |
|---|---|---|---|
| Findings | 26,153 | 37,966 | **+11,813** |
| Fixed | 202 | 217 | **+15** |
| Duplicate | 2 | 1,670 | **+1,668** |
| Withdrawn | 245 | 419 | +174 |
| 公表率 | 10.5% | 19.4% | +8.9pt |

**深掘り**: この台帳問題は [[concepts/ai-vulnerability-detection-at-scale]] の Cloudflare はるねっさ (Recon→Hunt→Validate→Dedupe→Report の8段) が解決しようとしている層そのもの — 検証なしの発見器は「スループットが上がった」のではなく「上流で放置した」だけ。Cloudflare が「narrow scope + adversarial review + 連鎖の分離」を原則化したのはこの noise 構造への反応。一方 [[concepts/alphaproof-code]] (Nov 10, HN 647pts) が Signal の**実コード**を formal verification したのは逆方向の答え — 「多数発見して人間に投げ直す」ではなく「限定的スコープで数学的に保証する」。両者並べると、AI security の frontier は「探索量 vs 検証可能性」の軸で割れている。さらに [[concepts/reasoning-as-pathfinding]] (HN 147pts) の「推論時の考え込みは RL 学習時探索の償還に過ぎない」仮説を適用すると、thinking budget を増やしても finding quality は頭打ちになる帰結が自然に出る — 検証層を外部に作るしかない。[[concepts/recursive-self-improvement]] の自動修復ループも、maintainer trust gap が閉じない限り同じ壁に当たる ([[concepts/agent-model-drift]] の信頼性問題とも連動)。
