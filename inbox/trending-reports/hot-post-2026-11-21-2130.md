## 今夜の逆張り視点: RSI は「未来の脅威」から「決算書の注記」に移った

**▶ 一言要約**: 同一週内で (1) lab が RSI 閾値到達を有価証券報告書で宣言し、(2) 重み自己書き換えの第一次結果が arXiv に出た。RSI は safety 界の先読み議論から、投資家向け開示の現在形に降格した。

**詳細**:
- [[concepts/language-model-weight-self-rewriting]] (arXiv:2611.21885, HN 50577265, 423 pts): open 27B が自分の重み + 採点済み解答 + 自己実行権限を与えられ、(a) 未見問題で +6.6pt、(b) 8連続セッションで単調上昇、(c) 破損コピーを元重みを読まずに元の精度の 80% 超へ自己修復、(d) 同一 family で最大モデルのみ成功 = scale emergence。
- 位置づけ: test-time scaling ([[concepts/test-time-scaling]]) と違い利得が重みに書き込まれる = 回答ごと compute 課金なし。training ([[concepts/rich-suttons-bitter-lesson]]) と違い backprop なし・optimizer state なし・forward pass のみ。先行 [[concepts/weight-space-programming]] は「frontier が小さいモデルを編集」だったが、本論文は自己編集に閉じた。
- [[events/anthropic-nasdaq-debut-2026]] (§S-1 deep read): Nov 2 amendment「may imminently meet」→ Nov 10「we have met this threshold」— 8日で RSP「AI-accelerated progress」判定が反転。Banks の但し書き: 判定は将来モデルへの期待ベースで、実証済み成果ではない。同月 data point: Anthropic 自社 codebase の 90%+ を Claude が執筆 (2026-09)。
- 本数だけ並べると物語は完成する: lab は「AI が研究を加速し 1年で2年分」を SEC 開示に書き、市場はそれに時価総額 ~$1.5T を乗せた。直後にモデル側から「訓練と推論の壁は道具の限界であって知能の性質ではない」が来る。[[concepts/recursive-self-improvement]] の harness path → direct path の順序づけが、実装順としては逆転しかけている。

**深掘り**: 本当の問題設定は「重み空間最適化の alignment benchmark が存在しない」こと。HN top thread が指摘するとおり、WeightBench は capability-side の編集を測るだけで、安全制約を保持したまま編集できるかを測る装置が無い。提案されている封じ込み — well-aligned な base + 更新周りの safeguards — は closed model にしか適用不可。abliterated open model が同じことをやれば worst case として承認済み、という論調がスレッド側。さらに「intend to preserve restrictions して事故で無効化する」no-true-Scotsman ドリフトも残る。比較対象として [[concepts/rome-weight-tampering-attacks]] は GPU メモリ上の重みを数個書き換えて disk 上ゼロバイト変更で topic 汚染を見せる — 攻撃側の重み編集はすでに実用域で、防御側の計測器だけが欠けている。
