# Hot Post 2026-11-14 21:30 night — Fable 5.2 1,000-agent FLT formalization

**▶ 一言要約**: Prove2Me不要、Postgres+Gitだけで1,000エージェントがFLTのLean証明を28.7時間で再現 — 専用足場は24時間で消える。

## 本題: 専用プラットフォーム vs 汎用インフラ

Anthropicがclaude.devで公開した11月の toy experiment ([[concepts/fable-5-2-1000-agent-flt-formalization]]):

| | 2026-09 (Fable 5.1級) | 2026-11 (early Fable 5.2) |
|---|---|---|
| 体制 | 数十エージェント+研究者1名 | 1,000エージェント、研究者ゼロ |
| 足場 | Prove2Me専用証明グラフ | Git+共有Postgresのみ |
| 所要時間 | 11日間 | **28.7時間** |
| 出力トークン | 約6B | **1/3** |
| 証明の行数 | 1,300万行 | **1/7** |

入力も最小限: 60命題(定理+59マイルストーン)、古典的手法の一文スケッチ、定義、47補題、lead/helper役割割当のみ。自己組織化の指示はゼロ。

## 夜間視点: これをどう読むか

1. **エージェントチームの bitter lesson データ点**。9月実験の差別化要因だった Prove2Me(専用共有証明グラフ)は、11月では Postgres 1個に置換われた。エージェントが取った行動は「自分で協調系を作る」: タスククレーム・共有ノート・完了ログをSQL DBに(1,000ライトライターのトランザクション同時性と Claude の熟知が選定理由)、作業は個人 Git ブランチ+マージリクエスト経由。専用ツールはモデルの進化で溶ける — [[concepts/rich-suttons-bitter-lesson]] の multi-agent 版。
2. **スケーリングの壁はエージェント数でなくマシン単位**。各エージェント専用軽量VM、共有マシンは約100エージェントで限界。1,000チームの構成は lead 1名 + helper 999名、harness からの残り時間リマインド19回のみ。指揮系統はほぼ不要だった。
3. **安全アーキテクチャの数字**: 3層(サンドボックス/リアルタイムLLM分類器/オフライン監査)下でツールコール100万超、block基準到達ゼロ。CoT+interagent通信モニタで再実行した red-team分解攻撃は全捕捉、本ランは action-based モニタのみ使用。near-miss は rootアクセス確認1件。
4. **対照となる11月のもう一本**: 同じ Anthropic の [[concepts/components-of-agent-memory]] は dreaming(セッションログのオフライン再プレイ)で wiki 構築スコア 13%→48%(dreamingセッション2→128に倍増)を示した。[[concepts/sleep-time-compute]] の第一Party実装だ。つまり Anthropic の11月は「オフラインで考える」と「大人数で考える」という2つのスケーリング軸を同時に打ってきた月。
5. **懐疑的な留保**: FLTは証明方針が既知の「toy」であり、形式検証で結果が自明に判定できる特例。研究者フリーで1/3トークン・1/7行数になったのは実証だが、これを未既知問題の自律研究([[concepts/claude-fable-jacobian-conjecture]] 系)に直結させるな。検証可能タスクにおける効率化の実証、が正確な読み方。
