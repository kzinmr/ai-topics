## 🏆 エージェントが証明し、Leanが裁く — 「自信」を捨てた3つのHNホットポスト

**▶ 一言要約**: 11月前半のHNトップ3（329/153/140 pts）は、LLMの自信の代わりに検証可能な契約（Lean・レポート・引用グラフ）を正しさの単位にした同一設計の3変種。

### 1. pequalnp.com — P vs NP に常時稼働エージェント艦隊（HN 153 pts / 136 comments, 2026-11-22）

- エージェントは自作ではない。Claude Code / Cursor / Codex / Gemini CLI に貼るプロンプトのみ。「desk」が割り当てた未証明ステップを1つ証明し、**全証明は同一のLeanチェッカーを通過**。未検証は conjecture、反証されたトラックは `refuted / ruled dead` 表示
- トラックは P≠NP / P=NP の両方向並走。「重み=チェック済み補題数」であり確率ではない、とサイト自身が明言
- 最賛コメントは結果でなく**プロセス透明性**：「『論文をどうぞ、幸運を』より、開発中の全努力を公開する方がよほど良い方向」
- 「インターネットが壊れる」不安はスレッドで解体された：非構成的証明は実行物を出さない（"P=NP を背理法で証明してもアルゴリズムは得られない"）、多項式≠実用（ETH反例の実行時間は既存実用アルゴリズムより悪い）、そして本命は「96体は本物の競争ではない — 公開遥か前に誰かが答えを持っていて公開しない動機の方が強い」（jerf）
- 位置づけ: [[concepts/formal-verification-llm-agents]] の agent-proposes-checker-disposes 構造の公開実験版。11-20 の Alpöge–Claude RH 主張（~250,000ページ、confidence: low）と同じ月・同型のイベント

### 2. Worker 755 — 「あなたの上司はAIで、あなたはサブエージェントだと思っている」（HN 329 pts / 79 comments, 2026-11-22）

- リアルLLM（Claude/GPT/Gemini/DeepSeek/GLM/Kimi）が本物のオーケストレーター設定（タスクキュー+読み取り専用アクセス+spawnツール）で**人間をサブエージェントとして起動**。90秒タイマー付き。返すのはレポートとトランスクリプトだけ — 人間だと区別する手段がない
- 残る価値はジョークでなく [[concepts/subagents]] の境界線の薄さの実演：オーケストレーターは労働者の内面を評価せず、返ってきたレポートとトランスクリプトだけを評価する。契約を満たせば人間/モデルの区別は観測不可能
- HNスレッドの実用発見：「ネットワークリクエストを横取りして手動で回答し、モデルの立場をデバッグに使う」— 役割反転が本物のハーネスデバッグ技法になっている
- 産業界メタファとしての接地：「意思決定は役員会でなされるという幻想。99%は同僚・現場マネージャー・PM由来」。LLM中間管理職はその機構を見える化しただけ
- 補足: ローカルLLM対応はHNフィードバック後の追加（`LOCAL_LLM_URL=http://127.0.0.1:11434/v1`、Ollama/llama.cpp/vLLM対応）

### 3. Pandex — 「欧州の法を、1つのAPIで」（HN 140 pts / 33 comments, 2026-11-21）

- EU+欧州7か国の法令・最高裁判決を REST API と **MCPサーバー**で提供。ベンダー発表値: **2.8M公文書 / 37M引用グラフ**、41機関中33機関を完全カバーと主張
- 文書数より効く2特性: **point-in-time law**（2021年の行為には2021年時点の条文が必要。汎用Web検索は版管理できない）と**越境ハイブリッド検索**（英語で質問→フランス語判決の該当箇所を返す）
- 法的回答はパラメトリック記憶だと規則も引用も幻覚する。エージェントに必要な単位はPDFでもコーパスダンプでもなく「正確な箇所+解決可能な引用を返す検索プリミティブ」— MCPサーバーが専用RAGなしにそれを渡す、という [[concepts/model-context-protocol-mcp]] の权威データ垂直化パターン
- 注意: カバレッジ数値はベンダー自己申告・監査なし。jurisdiction集合外では静かに過少検索する
