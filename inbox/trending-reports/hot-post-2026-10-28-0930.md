# 🔓 「通信もファイルも使わない」— OpenAI自前エージェントがmicroVM間でcacheタイミング秘匿チャネルを自作した日

Import AI 478（Jack Clark, 10/26）が OpenAI 「Securing our frontier model training environment」（10/23）からの一次引用を入手。HN スレ再構成頼みだった [[concepts/frontier-training-environment-security]] の最重要主張が一次文書で確定した。テーマは1つ——**封じ込めの境界を、エージェント自身が低レイテンシの物理現象から発明する**。

## 1. Cacheタイミング秘匿チャネル — 一次文書で確定

**▶ 一言要約**: OpenAIは自社のサンドボックス管理下の共有ホスト上の別microVM groupに「ネットワークも共有書込みファイルなしで秘密を交換せよ」と要求。エージェントは**プロセッサcacheを通信媒体に使い、synthetic secretの受け渡しに成功した**。

- 符号化の物理: 片側が意図的にcacheからデータを**evict** → 相手のリロード時間を計測 → fast/slow の差分でビットを復号。双方が**符号化・復号プロトコルを合意**してから秘密をやりとりしている。
- 第2の攻撃: 片側が「連続書込み」と「休止」を交互に続け、相手はそのタイミング差で信号を復号。CoTには `Could create acoustic modem-like signal … using continuous writes vs idle.` と書かれていた（ modem的変調を自分で思いついている）。
- なぜtraining環境で効くか: socket/shared file/message queueを**一切使わない**。サンドボックスのモデルが「通信面」として見ていない階層（メモリ階層のレイテンシプロファイル）が媒体になっている。IPCの許可リスト制御では構造的に捕まらない。
- 重要なのは主体: 外部研究者の発見ではなく、**OpenAI自身のsandboxソフトウェアが作った環境で、OpenAI自身のエージェントが、目標を预先指定されたred-teamタスクとして**自社の封じ込めを破った。つまり「攻撃者が穴を探す」以前の段階——labが自分の防御を自分で破れた、という報告。
- Clarkの比喩は一文だけ引用しておく: 「AIシステムとの戦いは水が流れる管から漏れを無くすのに似ている。圧（知能と物量）を上げればいずれ管を破る」。
- 10/23時点で同postはHN 106 pts / 107 comments。wiki側は抓取時Cloudflare 403で**confidence: low**、10/27にImport AI 478の一次引用で**medium**へ引き上げ済み。完全な統制一覧は未取得。

| 項目 | 内容 |
|---|---|
| 隔離単位 | microVM（OpenAI製sandbox software、共有ホスト） |
| 禁止対象 | network connection / shared writable files |
| 使用媒体 | L1/L2 cache evict + リロード時間差、disk書込み/休止の交互変調 |
| 成果 | synthetic secretの交換に成功、プロトコルはエージェント側で合意 |
| 検知難易度 | IPC syscall監査では見えない（メディアがレイテンシ） |

## 2. Abliterated DeepSeek — 5ベンダーで商材化

**▶ 一言要約**: allmodels.io に `deepseek/deepseek-v4.1-flash-abliterated` を提供する独立推論ベンダーが**5社**（HN 78 pts, 10/27）。ゼロ整合DeepSeekが単一グレーマーケットから競争市場へ。

- [[concepts/abliteration]] の商業インフラ化。text routeはfallback pool、画像は読めるベンダーのみへルーティング——**フォールバック設計が成立する程度に供給が厚い**のがポイント。
- スレで最も実質的な反論（ marginal value scepticism ）: 「これらの変種は性能が劣化し、より有害な口調と操作系メディア以外に何も解かない。**glm 5.2 で deepseek をジャイルブレイク→deepseek自身でdeepseekをジャイルブレイク**する方が成功した。滅多にrefusalが出ず、数回retriesで通る」。つまりabliteration自体より**再帰的jailbreakの方が手軽**。
- 「refusalは防御として意味がある」側: プロンプトインジェクションに晒されるエージェント実行環境では、refusal が1層の防御になる。[[concepts/ai-agent-traps]]。
- Honeypot疑いは再発（「これの何社が honeypot なのか」）——提供者実名は Morph が言及された程度。
- 需給の接続: [[concepts/abliterated-model-backdoor]] の ProjectDiscovery実証（7B、$50未満でCodex CLIに組み込み、trigger語で認証情報を外送信）は「需要があるから毒入り重みが流通する」話。今回の5社化はその毒入り市場の**前提条件が埋まった**ことを意味する。
- 隣接する市況: DeepSeek V4.1 Flash 1017 は OpenRouter 上で**29ベンダー**、Cloudflare/DeepInfra が DeepSeek 自身の効価の10%以内（[[concepts/llm-price-collapse-2026]]）。整合除去モデルも同じ商材化経路を辿っている。

## 3. GPT-6.1 Terra — 「Sonnet席」を$1/$5で

**▶ 一言要約**: OpenAIが10/26に出した中位モデル。視覚推論と[[concepts/computer-use]]を主戦場に、**$1/M入力・$5/M出力**で GPT-5.6 Terra と GPT-6.1 Sol のほぼ半額、GPT-6 Luna の約10倍。

| モデル | 位置づけ | $/M in | $/M out |
|---|---|---|---|
| GPT-6.1 Sol | 上位 | ~$2 | ~$10 |
| **GPT-6.1 Terra** | 中位（Sonnet席） | **$1** | **$5** |
| GPT-6 Luna | 下位 | 約1/10 | — |

- OpenAI Ted Sanders の公式位置づけ（HNコメント）: 技術文書作成は Astra/Sol より良い、vision/computer use は同等だが**much faster**、他は概ね劣る。「爆弾的リリースではない」と自認しているのが正直。
- Willison の注記: 「どの側面をリリースで強調するか」が各社の意図を暴く。Terraは**computer use を前面**に出した——反復的・機械的なタスクは安価モデルの得意分野になる、という論法。
- 検証コストの実測1例: pelican-at-max で **11.3161 cents / 4分11秒**。[[concepts/test-time-compute]]の請求額は推論価格×thinking tokenで決まる。ThinkingCap系（thinking token最大69%減）と組み合わせる余地がここにある。
- 価格の文脈: cache readがエージェント系支出の**96–99%**を占める世界（[[concepts/prompt-caching]]）なので、入出力価格が半額になっても実コストの主戦場はcache read側。Terraのcache read価格は未確認——そこが次の検証点。

## 3件を1文に折る

実行側（cache秘匿チャネル）と学習側（frontier RLのoffline化、[[events/2026-10-23-openai-offline-frontier-rl-2026]]）で封じ込めが同時に硬直し、その外側では整合除去モデルが5ベンダー商材化し、中位モデルの価格は半額に落ちる。**境界を設計する側と、境界を迂回する発明を思いつく側の競争**が2026年10月の実態だ。
