## 🔬 出力規制は紙でした — ウェイトの中の「148個のSM」が物語る、GPU密輸の計測可能性

**▶ 一言要約**: DeepSeek-V4〜Kimi K3 の6モデルが Blackwell 指紋 (49〜1,385σ) を持つ — 通関書類ではなく生成物がチップを証言する時代。

**詳細** (Unemployment Labs Nov 12, HN 307pts/114c / `raw/articles/2026-11-13_unemploymentlabs_checkpoint-forensics-blackwell-fingerprint.md`):
- 手法: B200/B300=148 SM、GB200/GB300=152 SM という SM 数が seed 初期化と tensor layout に残る。約6兆通りの seed-layout 組み合わせと照合し、ノイズ底 (~8σ) に対して **49〜1,385σ**、最低でも 20σ。公開 HW を明かす24モデルで一致率100% — NVIDIA 自身の Nemotron-3 Ultra(GB200 公称)も 152 SM と読める。
- 中国政府系4ラボ6モデルが Blackwell 判定: DeepSeek-V4-Flash / MiniMax-M3 (B200系)、DeepSeek-V4-Pro / Kimi K3 / K3.1-Pro / Ling-3.1-flash (GB200系)。輸出許可が下りたと報告された例はない。
- 転換点は鮮明: DeepSeek は V3 (2024-12) まで Hopper、V4 (2026-04) から Blackwell。Kimi は K2.5 (2026-01) まで Hopper、K3 (2026-07) から Blackwell。Qwen / GLM / Tencent / Xiaomi / StepFun は今も Hopper、Meituan LongCat-2.0 は NVIDIA 指紋ゼロ。
- 規模見積り: Kimi K3 ~4,500 / DeepSeek-V4-Pro ~3,000 Blackwell GPU(約2〜3ヶ月)。WSJ の ByteDance マレーシア36,000枚 $2.5B から逆算する単価 ~$70k で、5 run 合計は **$5億超**。
- HN の三大反論(論拠の強度を分けて保持): liuliu「PyTorch 実装 quirk 依存では?」/ 輸出規制の費用対効果論争「禁止は価格を上げるだけ、コンプライアンスコストは自国が被る」/ ワシントンの黙認仮説(Huang-Trump 問題、報告される $25M の贈答)。

**深掘り**: 効くのは結論(中国が規制を破ったか)ではなく、**検証の層が変わった**点だ。著者自身が「これは先端計算資源へのアクセスの技術的証拠であって、違反の証拠ではない」と書いている — 第三国データセンターでの受託訓練は合法で、中国国内のチップ保有も合法。だから政策論争は本来 [[concepts/cuda-moat]] が示す CUDA 移行コストの層に降りていくべきで、実際 2024 の DeepSeek-V3 衝撃でさえ移行コストを潰せなかった。指紋監視はモデルカード/provenance attestation の系譜(new page)の実装候補であり、[[concepts/us-china-ai-competition]] の4戦線のうち「intelligence」を計測可能にする道具になる。逆張り評価としては: 技術の寿命は PyTorch 依存性の解明とベンダー反論待ち。査読なし・単一ソース・政策アジェンダ強めの結果を「確定情報」として扱うのは [[concepts/ai-bubble-economics]] の循環融資データがそうだったのと同じ罠 — ただし、24/24 の自己検証を無視するのも同じ間違いだ。
