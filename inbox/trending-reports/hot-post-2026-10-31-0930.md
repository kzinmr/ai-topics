# 知識エコシステムの枯渇 — Mistral Large 4 重み開放 × 「AIが引用する数字の57%は研究に辿り着かない」

2026-10-31 morning slot / ai-topics hot post

## 1. Mistral Large 4 (Le Chonk) 重み開放 — 3週間の追加RLで open-weight コーディング首位

**▶ 一言要約**: 1TパラMoE (active 52B) が open weights 化。Terminal-Bench 4.0 はプレビュー比 +13pt の 41%、AA Coding Agent Index 48% で GLM-5.3 と同スコアながらタスク当たりトークン 47%減。

**詳細**:
- 2026-10-06 の public preview から約3週間、追加 RL のみで引き上げ。[[concepts/mistral-large-4]] のプレビュー時スコア 28% → 41% (Terminal-Bench 4.0)、出力トークン 30%減。
- Cognition 非公開ベンチ FrontierCode 2.0 で **19.7% 首位** (GLM-5.3 19.3%、DeepSeek V4.1 Flash 17.8%、Kimi K3 17.3%)。「メンテナがマージするか」を問う評価での首位は初。
- Surge Code ブラインド勝率: GLM-5.3 に 64%、Kimi K3 に 64%、DeepSeek V4.1 Flash に 56%、**Claude Opus 5.5 に 22%** — 評価対象中 Opus 5.5 だけを下回る。
- サイバー防御: AA Cyber Index 51%、悪性要求への refusal 平均 96.6%(open model 中最高)。[[concepts/mistral-large-4]] がプレビューで主張した「Cybench 93%」「脆弱性 patch 82%」は開放版で再集計され、Cyber Index 側の数値に置き換わった。
- 価格: **$0.70 / M input、$0.07 / cached、$2.10 / M output**。reasoning 3段階 (Low/Medium/High) でコスト-精度を連続的に選べる。
- ライセンスは Mistral Ecosystem Open-Weight (= MIT 改変版)。MaaS 事業だけ別途商用ライセンス必須。[[concepts/open-weights-licensing-tightening]] の系譜。
- 欧州主権 AI の売り込みとして Booz Allen / Cisco / Cloudflare / CrowdStrike / ENISA / Orange Cyberdefense / ABN AMRO / Crédit Agricole のエンドースメントを一斉公開。[[entities/mistral-ai]]、[[concepts/sovereign-ai]]

**深掘り**: 事前学習は European Grace Blackwell 3,800 GPU でスクラッチ。B3 Agent Security Benchmark の攻撃耐性は preview 93.3% → 97.1%。BrowseComp は SFT checkpoint 75% から RL で 84.5%。Mistral は「プレビュー後にライブトラフィックで black-box 攻撃の試行を観測、guardrails を修正中」と明記しており、cyber capability 開放と運用リスクの板挟みを公開文書で認めた形。フル技術レポートは未公開なので、プレビューからの改善が RL 由来か評価プロトコル差分かは分離できない。

## 2. Zombie Statistics — AI が引用する数字 1,285 件のうち研究に辿り着いたのは 40%

**▶ 一言要約**: Trakkr Research が 5 アシスタント × 200 質問から引用統計 1,285 件を追跡、同一の研究に辿り着いたのは 40%。「研究が存在しない」11% +「検証不能」40% で 57% が追跡不能。

**詳細**:
| 追跡結果 | 割合 |
|---|---|
| Sourced — 研究が存在し同じことを言っている | **40%** |
| Changed — 研究はあるが数値/対象/年が異なる | 8% |
| Can't check — 名前付きソースに含まれない/有料化/消滅 | 40% |
| Nowhere — どの経路にも研究が存在しない | **11%** |

- 典型例「44% の営業担当は1回のフォローアップで諦める」— 5 アシスタントすべてが同一表現で引用、**背後に研究が一件もない**。
- 同一質問に対する数値ドリフト: 「paycheck to paycheck」48–59%、「小企業のうち web サイト保有」73–83%。
- 別調査: Google AI Overviews の 52,930 回答 (2026-09-25〜10-25) を監査。統計を載せていたのは 4.4%、手作業で追跡した 300 件は同じ ~40% プロフィール。
- 典型的な hallucination とは機序が違う。数字は通常 listicle / アグリゲーター由来で、モデルは「もともと出典のない数字」を忠実に再生产している。故障箇所は情報エコシステム側。[[concepts/zombie-statistics]]、[[concepts/zombie-internet]]
- 留意: Trakkr は「AI に引用されやすくする」ツールを売る商業ベンダーなので動機は引用失敗を発見する方向に寄る。方法論と per-statistic trail は公開済み、11% Nowhere + 40% Can't check の内訳は既存の link rot 文献と整合。HN 167pts (2026-10-28)。

## 3. 同じ週に出た 2 つの数字が指すもの — 供給源の枯渇

Stack Overflow の新規質問が月 1,000 件割れ ([[concepts/stackoverflow-question-collapse]]、HN 789pts/718コメント) と同日帯に出た 2 つの調査は、表層は別々でも同じ配線を指す。

| 調査 | 測ったもの | 数値 |
|---|---|---|
| Stack Overflow | 人間が書いた公開Q&A の**供給量** | 月 <1,000 件 (2026-10) |
| Trakkr | AI が再生产する統計の**検証可能性** | 40% |
| Trakkr (AIO) | 検索側の AI 回答に含まれる統計の割合 | 4.4% (52,930件中) |

ループは閉じている: コードモデルの pretraining/retrieval 素材だった SO を、その主要消費者であるコーディングエージェントが代替した。供給が細る最中に、エージェントが生成する無出典の数字が次のコーパスへ混入する。[[concepts/model-collapse-of-viewpoints]] は単一世代内の立場多様性の収縮を扱い、[[concepts/synthetic-data]] 系の classic model collapse は合成データ再帰による分布末尾の劣化を扱う。Zombie Statistics はその中間、**人手検証されていない数字が一次ソースとして流通し続ける状態**を測っている。

Mistral の「open weights + self-hosting + 欧州法下のデプロイ」は、この層への依存を API 経由でなく自前で持つという回答。[[concepts/open-weight-vs-closed-llm-gap]] のギャップ短縮議論が能力の話に留まる一方、ML4 の売りは依存先の多様化として位置づけられている。
