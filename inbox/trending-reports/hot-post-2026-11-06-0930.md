# Together Compiler が自社の megakernel を否定した — 「静的形状の最適化は死んだ」の生産環境版 (2026-11-06 09:30 JST / morning)

**▶ 一言要約**: Together AI が TKCC で [[concepts/megakernel-inference|megakernel]] を「the right design goal ではない」と自己否定 — エージェント実験ループは従来方式の **252倍** のスループットで、Llama 1B の megakernel ベースラインを **1.7倍** 上回った。

## 何が起きたか — 「手書きカーネルの1週間」が「エージェントの24時間」に置換われた

[[entities/together-ai]] が 11/5 に公開した Together Compiler (TKCC) は、推論最適化を「コンパイル変換問題」から「エージェント探索問題」に組み替えたもの。数字はすべてベンダー報告（SemiAnalysis の独立検証なし）。

| 項目 | 従来 (vLLM/SGLang 再起動ループ) | TKCC (永続エンジン+ホットリロード) |
|---|---|---|
| 1実験あたりの起動 | 467 s (重み読込50s、JIT warm-up 93s、autotuning 193s 含む) | **9.0 s** (CUDA-graph capture 7.3s) |
| 実験スループット | ベースライン | **252×** |
| 最適化所要時間 | 人手で数日〜 | **24時間以内で最大 2.6× TPS** |

- 対象は Kimi K3 / GLM 5.3 / MiniMax M3.1-Flash / DeepSeek v4.1-Flash の4モデル。[[concepts/ai-benchmarks/agentx-inferencex|SemiAnalysis InferenceX/AgentX]] の最高公開設定から全6モデル/チップ組で性能フロンティアを更新した、と同社主張。
- batch-size-1 SOTA 例: MiniMax M3.1-Flash **1111 TPS**、DeepSeek v4.1-Flash **1205 TPS**。
- LLM 外にも一般化: 気象・PDE・時系列・生物の4コードベースで、Claude Code `/goal` 比 3/4 のモデルでより大きな高速化。汎用 AI コンパイラとして社内運用中。

## 「megakernel は dead」論争に、原作者自身がトドメを刺した

8月の [[concepts/megakernel-inference|megakernel 論争]]（Lucebox の RTX 3090 411 tok/s vs M5 Max、Ali の「dead」論）への最新返信が、皮肉にも megakernel 派の Together 自身から出た。

- 同社の初期 megakernel は「batch-size-1 の Llama 1B という単一的静的形状」の周りに設計されていた — 公開トラフィックの形状が動くと即座に陳腐化する。
- 根拠となった自社トラフィック統計（推論事業者による workload 公開は希少）: **OpenRouter トラフィックの80%が直近3ヶ月リリースのモデル**、OpenRouter OSS top-10 に同一アーキテクチャなし、リリース2週間でプロンプト長 +80%、国家間でプロンプト長 1.4倍差 (97k vs 70k)。
- MoE のようにexpert起動がデータ依存なプリミティブでは、ランダム入力の単独カーネル最適化が体系的に誤誘導する — TKCC の2層エンジン（高速反復用/実データ検証用）はこの問題への直接の回答。

## 「推論エンジンを書く」こと自体がコモディティ化する兆候

[[concepts/resin]]（Thinking Machines の Eric Zhang による推論エンジン部品ライブラリ）は同じ方向を別角度から突く: Blackwell 上で DeepSeek-V4.1-Flash と GLM-5.3-Flash のエンジンを **約12時間で vibe-code**、スループットは vLLM/SGLang に匹敵（自称）。

| | Resin | TKCC |
|---|---|---|
| 戦略 | エンジンを「just code」の部品群に分解 | エンジンの再最適化をエージェントに委任 |
| 人間の仕事 | ハードウェア特化カーネルを書く | 探索予算とコストモデル designing |
| 前提 | 次世代モデル/HWがモノリスを追い越す | トラフィック形状が常時ドリフトする |

両者とも「vLLM/SGLang をプロダクションで使うな」とは言っていない。崩れているのは、手書きカーネルの専門性が数年の参入障壁になるという前提だ。TKCC の RSI 主張（[[concepts/recursive-self-improvement]]）は「推論システムを、そのシステムがサーブするエージェントが最適化する」ループを指す — Lilian Weng が harness RSI のボトルネックとした**実験速度**そのものを攻撃対象にしている。

## 注意点

- TPS/SOTA 数値はすべて Together 自社ベンチマーク。InferenceX 主催の SemiAnalysis による検証は未公開。信頼度: medium。
- Trainium2 計測は合成マルチターンデータセット（ISL 70k、キャッシュ97%、OSL 700）使用 — 高並行未対応の開示あり。
