## 🕯 决策モデル戦線 — 先週最も見落とされた3連発

**▶ 一言要約**: 11/11にGoogleが Gemini Decision 1 を投入し、Jev($0.042/MTok)・GPT-6 Luna($0.10)と3ベンダー体制が確立。出力価格は3社とも無料。

**詳細**:
- [[concepts/system-one-models]]( Kahneman の System 1 由来) = 自由文を出さず、typed な決定(yes/no・choice・rubric评分)だけを返すモデルクラス。TypeSafe AI の **Jev**(2026-09-15)が創始。
- [[entities/gemini-decision-1]] は Jev の API をほぼ踏襲 — yes/no 質問を指す Jev 用語 **"Noul"** まで流用。違いは2点:
  | | Jev | GPT-6 Luna | Gemini Decision 1 |
  |---|---|---|---|
  | 入力 | **$0.042**/MTok | $0.10 | $0.10 |
  | 出力 | 無料 | 無料 | 無料 |
  | モダリティ | text+JSON | text+画像 | text/画像/音声/動画/PDF |
  | yes/no出力 | 飽和 1.0/0.0 | 飽和 1.0/0.0 | 非飽和(例 0.9234) |
- Simon Willison の動画テスト(Yonkers robot, 4問)では Gemini だけ中間確率を返した → [[concepts/calibrated-escalation]] の信頼度閾値ルーティングに有利な可能性。ただし未検証。
- 背景: Sean Goedecke が9月に「Jev が traction を得たら frontier lab が公式高速決定版を出す」と予測。OpenAI が先に実行し、Google が語彙ごと追随した格好。
- 隣接する新概念: [[concepts/recursive-decision-models]](Weitekamp, 2026-10-01)。決定モデルに再帰的セルフコール + 外部化コンテキストを持たせ「fan と funnel のカスケード」を作る。DSPy の `dspy.experimental.Noul` で表現可能。11/11 の aiDotEngineer 講演 "Your Agent Doesn't Need an LLM for Every Decision" で、その延長線上の **oSo**(computer-use 決定エージェント)と **Operating System One** が予告された。
- 使いどころの具体例: 決定モデル驱动的バイナリサーチ —「この文章に答えがあるか?」を Noul で問いつつ `look` ツールでテキストを半分ずつに畳む。生成モデル不使用。

## ✈️ United のエージェント予約禁止 — 「セキュリティ」説と「価格差別防衛」説

**▶ 一言要約**: 11/11 United がユーザー側AIエージェントによる予約を禁止(HN 569pt/約585コメント)。同じ負荷のKayak/OTAは野放しという非対称が核心。

**詳細**:
- 禁止対象は「未認可の第三者パーソナルAIエージェント」。旅行代理店/アグリゲータ経由の間接適用まで契約で reach している。指名された消費者エージェントは Meta の **Muse** と OpenAI の **dots**。
- 公式理由は credential exposure と連邦規則(受託手荷物の対面確認)。しかしスレッド側の支配的解釈は中間管理と価格支配の防衛:
  | 説明 | 根拠 |
  |---|---|
  | セキュリティ/責任 | United 声明 |
  | 中間業者の支配 | Harteveldt: 「Google検索・メタサーチ・OTAに既に苦しんでいるのに、より強力な仲介を増やせない」 |
  | GDS per-query 経済 | 「look to book」上限超過で検索1件≈1¢、Sabre API call 数¢ |
  | 価格差別の防衛 | エージェントは数分ごとに変動するセグメント横断価格を探れる=価格差別への規律 |
- GDS コスト説は弱い — 同じクエリを既存仲介も出している。強いのは最後の解釈。[[concepts/ai-industry-economics]] の中間業者キャプチャ理論そのもの。
- 市場は結束していない: 同時期 Southwest は ChatGPT ユーザーへの在庫閲覧を許可。ゲートキーピングが儲かるかは協調問題で決まる。
- 概念化: [[concepts/agentic-representation-gatekeeping]]。従来型bot遮断と違うのは (1) エージェントには本人の権限(principal)がある、(2) プラットフォーム側自動化は許容・ユーザー側だけ禁止という非対称、(3) 供給チェーン経由で強制、の3点。
- 対抗レイヤーは [[concepts/agentic-commerce]] の共有支払トークン(SPT: seller-scoped・時間/金額バウンド)と [[concepts/agent-identity-and-reputation]] の検証可能委任。これらが揃った後に United が「認可の有無に関わらずエージェント禁止」へ言い換えるかが観察点。

出典: wiki/concepts/agentic-representation-gatekeeping.md (raw/articles/2026-11-12_cbs_united-airlines-ai-agent-booking-ban.md, HN 50458900)

## 🔬 重量空間プログラミング — 局所モデルでの再現結果が出た

**▶ 一言要約**: MIT CSAIL の「LLM が重量を生で読み書き」論文(HN ~2,750pt)を、Willison が Qwen 3.8 27B のローカル実行で 4ゲーム中3識別に成功。ただし1問46〜64分。

**詳細**:
- 元論文 "Sparks of Weight-Space Programming"(2026-11-02, Takehi/Teoh/Zhang/Khattab)の3結果:
  | モード | 結果 |
  |---|---|
  | Read | ツールなしで 17,253 重量から学習ゲームを推定 — Breakout を 99% で当てる |
  | Write | 環境フィードバックなしで PPO 1億ステップ学習ネットを上回るゲームネットを合成 |
  | Fix | Qwen3.5-0.8B の **0.016%** の重量のみ編集で MATH-500 7.9%→48.1%、IFEval 3倍 |
  | Repair | 一度も成功しない方策を重量 3.5% の一発編集で成功率 0%→100% |
- Willison の独立再現(no-tools の Read 実験のみ)が本紙 lacks していた外部チェック:
  | ゲーム | 判定 | 時間 | reasoning tokens | 本人申告信頼度 |
  |---|---|---|---|---|
  | Pac-Man | ✅ | 46m12s | 43,506 | 72% |
  | Pong | ✅ | 1h04m54s | — | 75% |
  | Breakout | ✅ | 52m25s | — | 88% |
  | Freeway | ❌(Pac-Man系と誤読) | — | — | — |
- Kimi K3.1 Pro (OpenRouter) は Breakout を 9m41s / 19,493 reasoning tokens で正答 = ローカル Qwen の約5倍速。
- 留保: 実証は ≤0.8B の手作業で覗ける規模のみ。frontier 規模は未検証。「創発か、实验室がRSI系のMLタスクで明示的に最適化した能力か」がスレッド支配的疑問(vineyardmike 他)。OpenAI の公式言及がない点は創発示唆だが推測の域。
- 両刃性: 同じ重量読解力は backdoor の植入と検出の両方を可能にする → [[concepts/recursive-self-improvement]] の再点火(重量外科による)と [[concepts/sandbox]] の教育環境セキュリティ論に直結。
- 隣接する局所実行系の話題: [[entities/modal-labs]] が 11/11 KubeCon で gVisor の CNCF 移管に名を連ねた(gVisor はユーザー空間カーネル Sentry で「プログラムにはLinux、ホストには素直な1プロセス」が見える状態を作る)。エージェント実行環境の分離レイヤーが決算書に載る段階に入った。
