## Why it matters

Cloudflare Workers' isolate-reuse semantics are the substrate for cheap, stateful agent sandboxes built on V8 isolates + WebAssembly. Colvin's interest is direct: Pydantic's **Monty** Rust interpreter is designed to run in a wasm/isolate sandbox with sub-millisecond restore, and Monty's value proposition (snapshot/restore of a whole interpreter as a few-KB value) only pays off if the host isolate stays warm across connections. WebSocket upgrade requests appear to bypass warm-isolate reuse entirely, and `placement.region` can fan a single logical session across many isolates — together producing cold-start rates far above Cloudflare's own published "shard and conquer" warm-request model.
