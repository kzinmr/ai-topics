# Lovable — changelog highlights and funding news

**Scraped**: 2026-09-27. Note: the ElevenLabs GTM-coach webinar recap page (2026-08-06) now returns 404 on lovable.dev.

## Funding & valuation timeline

- **Jul 2025**: Series A of $200M described as "the fastest all-in-one software engineering platform to reach $100M ARR" (TechCrunch).
- **Aug 2025**: Accenture–Lovable partnership announced (TechCrunch).
- **Feb 12, 2026**: Series B of **$400M at $6.6B valuation**, led by **Menlo Ventures** (CNBC, TechCrunch, Bloomberg).
- **Jul 2026**: reported **$400M ARR** — "more than doubled since February" (TechCrunch).
- **Aug 2026**: **$400M raise at $13.3B valuation** (wiki-recorded; doubles the $6.6B valuation within eight months; co-led by Menlo Ventures + EQT Scaleup Europe Fund, with Tencent and Balderton; ~$600M annualized run rate). Note: some Aug 2026 press also cites the "$6.6B valuation, $400M raised" figures — these refer to the February round; the August round's $13.3B figure comes from the wiki's earlier ingestion of Aug 2026 reporting.

## Changelog highlights (Jun–Sep 2026)

### Sep 2026
- **Introducing Lovable Agents** (Sep 24, 2026): "agentic layer for builders — assign roles to agents, set work to be done, and the agent takes it from idea to working software."
- **Lovable 2.0 release** (Sep 17, 2026): the 2.0 launch post links to an **academic paper** introducing a new coding-agent **benchmark** (docs.lovable.dev/projects/releases/2-0).
- **Enterprise-ready AI workspace**: SOC 2 Type II compliant, GDPR ready, full SSO.
- Integrations: monday.com, ClickUp, Klaviyo, HeyGen, HubSpot Marketing, Microsoft Teams (GA), Microsoft 365 suite (Outlook/OneDrive/SharePoint/Excel/PowerPoint/Graph), Azure Blob Storage.
- Skills shareable across workspaces; visual page selection; live project chat; improved code viewer/search (monaco); drag-and-drop images onto files.

### Aug 2026
- **Workspaces** (org-level grouping of projects/members/roles); custom user roles (builder/editor/viewer); org-level skill settings; cost governance on workspaces.
- Background agents: view & continue across projects; agent todos; Devin/MCP connection to GitHub Cloud-hosted runners; better repo sync conflict resolution.

### Jul 2026
- **Projects 2.0** (redesigned project view, activity feed); agent profiles; agent rules (project, workspace, org levels); agent automations (scheduled tasks); agent tasks (background, from Slack); improved browser automation.
- **Lovable for Windows** desktop app; redesigned sidebar & dashboard; custom Lovable domain (remove lovable.app branding); cost governance dashboard; Cloud Armor for Google Cloud backend; org-level security assessment; audit logs (Enterprise); skill approvals (org level).

### Jun 2026
- **Skill Editor** (AI-guided skill creation); **Visual Edits** (direct UI editing in preview); workspace-level agents; project-level cost limits & spend tracking (up to project/organization level).

## Product trajectory

2026 arc: skills/agents primitives (Jun–Jul) → org/workspace governance + enterprise security (Aug) → **Lovable 2.0 + Lovable Agents** (Sep). The company is repositioning from "vibe coding app builder" to an enterprise AI software workspace with autonomous agents, and publishing academic benchmark work to support its coding-agent claims.
