# Marx diesel freight train set 9613

Source: https://dfarq.homeip.net/marx-diesel-freight-train-set-9613/?utm_source=rss&utm_medium=rss&utm_campaign=marx-diesel-freight-train-set-9613

The Marx diesel freight train set number 9613 was an early 1950s electric train set featuring twin diesel locomotives pulling 7-inch freight cars, sold through Montgomery Ward. It’s an attractive set and a very good example of post-war tin lithography, which was becoming something of a lost art at the time.
Marx diesel type electrical train set 9613
The Marx diesel freight train set 9613 dates to around 1950. It’s essentially the same set as set# 9500, with a nicer transformer.
The set consisted of two diesel locomotives numbered 6000, one powered and one dummy unit, and a caboose lettered for the Southern Pacific, which was one of the largest railroads west of the Mississippi River at the time. 9500

Other set contents
The 9613 set also included an oval of O27 track and a 50 watt transformer, model 1249 with circuit breaker. This transformer had a set of fixed-voltage posts for accessories running at 13 volts. Marx often gave exclusives to big retailers that were very similar to sets everyone else sold. Marx set 9613’s special thing that made it exclusive was including a slightly nicer transformer. The wattage was the same, but the transformer in the 9500 set didn’t have the accessory posts.
Having the nicer transformer gave Montgomery Ward a chance to push powered accessories as an add-on with the set. Or to sell accessories to them the next year. Part of the business model was to sell the train set one year, and sell expansions for several years after.
What was Southern Pacific?
The Southern Pacific was a Class 1 railroad that operated mostly in the southwestern United States, operating around 13,000 miles of track at its peak. Its track ran through the major cities in California, so this set would have had more appeal in the western United States than a set lettered for, say, the New York Central or Pennsylvania railroads.
The Southern Pacific merged into the Union Pacific in 1996. Southern Pacific has an interesting history beyond railroads. It ran telegraph lines alongside its railroad tracks, taking advantage of the value of the right-of-way, and in the 1970s it started using those lines for long distance telephone calls in competition with AT&T. They called the service Sprint and eventually spun it off into a separate business, the telephone company that merged with T-Mobile in 2020.
Other sets lettered for the Southern Pacific include the aforementioned 9500 set and the
9365
steam set.
Value
I typically see boxed examples of the 9613 set sell for around $100 shipped. Having original paperwork and a box in nice condition helps the value. Boxed examples are reasonably common, because Marx shipped them in sturdy boxes that worked well for storage, and the owners frequently boxed the set back up for storage when they weren’t using it.
