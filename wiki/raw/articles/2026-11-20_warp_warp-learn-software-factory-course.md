# Introducing Warp Learn: Build your first software factory

**Source**: [https://www.warp.dev/blog/warp-learn-software-factory-course](https://www.warp.dev/blog/warp-learn-software-factory-course)

Company
Introducing Warp Learn: Build your first software factory
November 19, 2026
Software factories are changing how software gets built.
Developers are already using coding agents to write code, fix bugs, and ship features. But building a software factory requires more than running individual agents. It means designing a system that can coordinate work, verify results, measure performance, and improve over time.
This brings in a new kind of engineering discipline: factory engineering.
Today we're introducing
Warp Learn
, a free, hands-on course to help developers learn the fundamentals of factory engineering and build their own software factories with Warp.
Learn by building
Our first course,
Build a Self-Improving Software Factory
, takes you from the fundamentals to building a complete software development loop.
The course is organized into three units:
Unit 1: Getting started
Learn what software factories are, what factory engineering entails, and the core components of a factory. Get set up with Warp Factories and explore agents, automations, runners, skills, scorers, and benchmarks.
Unit 2: Build the factory
Start with a single implementation agent and build toward a complete development workflow.
Connect your issue backlog, introduce human judgment with triage and spec writing, build trust with verification and merge-risk assessment, and automate bug fixes using error-monitoring webhooks.
Unit 3: Measure and improve
Learn how to measure and improve factory performance.
Evaluate agent quality with scorers, use self-improvement agents to propose fixes to common failure modes, and run benchmarks to compare different models and factory configurations across cost and quality.
Start learning today
The first two units of
Build a Self-Improving Software Factory
are available now.
Start learning on warp.dev/learn
Start your software factory
Book a demo and we’ll walk you through the workflows that map to your stack.
