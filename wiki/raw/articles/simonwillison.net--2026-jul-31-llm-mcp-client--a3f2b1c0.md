# Release: llm-mcp-client 0.1a0

Access tools from MCP servers as LLM tools.

GitHub release: https://github.com/simonw/llm-mcp-client/releases/tag/0.1a0

See [this blog entry](https://simonwillison.net/2026/Jul/31/stateless-mcp/#llm-mcp-client) for details.

## Context

This is a beat/release note by Simon Willison, posted on 31st July 2026. The llm-mcp-client plugin enables LLM tools to access MCP (Model Context Protocol) servers, connecting the LLM CLI ecosystem with MCP tooling. See the related blog post on stateless MCP for the full story.
