# Warp now supports linked billing with Claude Platform

**Source**: [https://www.warp.dev/blog/warp-now-supports-linked-billing-with-claude-platform](https://www.warp.dev/blog/warp-now-supports-linked-billing-with-claude-platform)

Warp now supports linked billing with Claude Platform
Warp
|
November 17, 2026
You can now link your Claude Platform organization directly to Warp with linked billing from Anthropic.
This integration lets you use supported Claude models in Warp without sharing an API key.
Here's how it works:
Link your organization.
Link your Claude Platform organization to Warp without sharing an API key.
Approve and control spending.
Authorize the link and set a spend limit for Claude API usage billed to your organization.
Pay Anthropic directly.
Claude API usage through supported linked billing features is billed directly to your Claude Platform organization by Anthropic.
Stay in control.
Unlink your Claude Platform organization from Warp at any time.
Linked billing gives teams a straightforward way to use Claude in Warp while keeping billing and spending controls with their existing Claude Platform organization.
Get started
Link your Claude organization to Warp to start using linked billing today. Visit
http://docs.warp.dev/agents/inference/claude-platform-linked-billing
to get started.
