Muru
. Graham Dumpleton started
mod_wsgi
20 years ago, and has been thinking about the ideal way to serve Python web applications in production ever since.
Muru is his new, AI-assisted Rust server that aims to provide the best possible tools for running ASGI and WSGI Python apps both in development and production.
As
he did with wrapture
