# Qwen3.8-Max Release Announcement

- **Source**: https://qwen.ai/blog?id=qwen3.8
- **Published**: August 3, 2026
- **Author**: Qwen Team (Alibaba)
- **HN Discussion**: https://news.ycombinator.com/item?id=49150470 (623 pts)

## Summary

Qwen3.8-Max is officially released as the most capable model in the Qwen family. This marks the first time Alibaba will open-source the weights of a Qwen-Max-class model, with open weights expected the following week.

## Key Announcements

- **Qwen3.8-Max**: Top-tier model with official support for `reasoning_effort` parameter (xhigh/medium/low) for adjusting reasoning depth and controlling cost
- **Qwen3.8-27B**: Dense model also being released as open-weight. Qwen3.6-27B was widely regarded as one of the best local models, and 3.8 aims to improve upon it
- **Self-evolution**: The model "self-evolves through feedback loops"
- **Long-horizon autonomy**: Qwen3.8-Max was used to create the "oh-my-cli" project from scratch in a 10+ day long-horizon autonomous coding run, building a self-evolving harness
