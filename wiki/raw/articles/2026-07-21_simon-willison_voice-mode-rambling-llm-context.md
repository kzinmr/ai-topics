# Simon Willison: Voice Mode Rambling as LLM Context Strategy

> "One pattern I find useful for working with LLMs is a nice long ramble session. Sometimes the LLM needs more bits to understand what you're trying to achieve, but you're too lazy to type them. In these cases I like to lean back, switch to /voice and just ramble for like 10 [minutes]"

Simon Willison shares a practical pattern for LLM interaction: using voice mode for long-form context dumping. When a task requires extensive context that's tedious to type, voice input enables natural, flowing context transfer. This is an extension of his "agentic engineering" philosophy — treating context transfer as a first-class engineering concern, and using the lowest-friction input modality to maximize the information density of prompts.
