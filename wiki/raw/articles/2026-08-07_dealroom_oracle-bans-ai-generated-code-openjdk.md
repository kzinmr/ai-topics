# Oracle Bans AI-Generated Code from OpenJDK

## Extracted Content

## Context

Oracle has explicitly banned AI-generated code contributions to OpenJDK, the open-source Java implementation. This is significant because:

1. **Larry Ellison's contrasting position**: Oracle's co-founder has made public claims about embracing AI, making this policy a notable institutional tension.
2. **Open-source governance precedent**: This is one of the first major open-source projects to explicitly prohibit AI-generated code contributions, setting a potential precedent for other projects.
3. **Legal motivations**: The likely driver is IP liability — if AI-generated code inadvertently copies copyrighted code, the project could face legal challenges.
4. **Alignment with other policies**: This joins a growing body of AI code policies from organizations like the Linux Foundation, Apache Foundation, and corporate open-source programs.
