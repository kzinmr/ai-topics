# What's New: October Disclosure 2026

**Source**: [https://www.hebbia.com/blog/whats-new-october-disclosure-2026](https://www.hebbia.com/blog/whats-new-october-disclosure-2026)

What's New: October Disclosure 2026
Product
By Aabhas Sharma
10.05.26
Memory, MS word plugin, version history, new data sources, and more are now live in Hebbia.
Last month, we shipped memory and version history for Max, new workflow and formatting logic in Matrix, and new data sources covering global markets, credit research, and deal pipelines.
Max
Memory
Max can now store and recall context across conversations, with explicit controls to create, review, and delete what's remembered. Admins enable memory at the org level, so your org controls what stays in context.
Version History on Deliverables
Artifacts like decks and docs now keep a full version history, so you can see what changed, reference an earlier version, and roll back when needed.
Audio on Mobile
Audio can now play in the mobile app, with transcripts viewable alongside them. Playback continues when the device is locked or the app is backgrounded, so you can keep listening while doing something else.
Smarter Skills in Max
Max now stitches multiple skills together in a single message. Type '/' to bring in each one you need and run them together on the same request. The slash command also surfaces your most recently used skills first, so finding what you reach for is as fast as running it.
Agent Creation, Search, and Scheduling
Search for, create, and schedule chat agents directly in Max. Find an existing agent by describing what it does or build a new one, and schedule it to run once on any future date, such as the day after earnings or a contract renewal.
Matrix
Column Run Conditions
Matrix columns can now trigger off the output of a prior column, so a workflow only runs the next step when your conditions are actually met. Build multi-stage analysis that skips irrelevant paths automatically instead of running every column on every row.
Conditional Formatting
Matrix now supports AND/OR logic to control cell-level formatting, so results highlight automatically based on the conditions that matter to your analysis. Flag outliers, thresholds, or exceptions the moment a column runs.
Other Updates
MS Word Plugin
Access Hebbia inside Microsoft Word, so you can run workflows directly in the tool where you’re working. Pull research, generate analysis, or draft a section without switching out of the document you're already working in.
Notifications
Start your work and we'll let you know when it's done. A notification center surfaces job completions, shares, and project updates as they happen, so you don't need to sit and wait or keep checking back.
Tokyo and Australian Stock Exchange Data
ICE market data in Hebbia now covers TSE and ASX-listed tickers, live and historical. Ask about price performance, volume, and trends across Japanese and Australian equities the same way you would for US and European names.
Intralinks Data
Intralinks, a global leader in data room intelligence, is now available in Hebbia. Content in Intralinks syncs directly into Hebbia, giving deal teams a continuous stream of data for their analysis.
Dynamo Data
Sync documents from Dynamo, a deal-pipeline management and CRM platform, directly into Hebbia. Pipeline records stay connected to the research and diligence already living in Hebbia, without a manual export or re-upload.
