# Build the Workshop Before the Software Factory — Armin Ronacher, Earendil

Source: https://www.youtube.com/watch?v=JNexz3Tbiu8
Channel: AI Engineer | Published: 2026-11-22 | Speaker: Armin Ronacher (@mitsuhiko)

Earendil's Pi coding agent has the same core tools it had a year ago, yet it does far more because the models got better. Armin Ronacher shows his own session data: fewer corrections, tasks running 14 minutes instead of two and a half, and 141 projects started but only 10 to 15 kept alive. His case: human attention is still the limit, so build a workshop that produces excellent software before building a factory that produces more of it. He also covers knowing when to push back on an agent, open formats, durable agents and code mode.
