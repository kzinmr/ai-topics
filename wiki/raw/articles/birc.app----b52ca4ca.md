# a native IRC client for macOS

Source: https://birc.app/

~ native macOS irc
A native IRC client for macOS.
bIRC implements the IRC client protocol — RFC 1459 as updated by RFC 2812 — plus a wide range of IRCv3 extensions.
/features
Everything an IRC regular expects.
IRCv3 support, in an interface that works like the rest of your Mac.
For a long time, Textual was the best IRC client on the Mac.
Now that it has been sunset, and IRCv3 features keep on coming (slowly but surely), I hope bIRC can be of some use.
/native
A native Mac app
Native windows and toolbars, split views, semantic colors, and system notifications. Not a web wrapper.
/ircv3
IRCv3 support
Message tags, server-time, batches, CHATHISTORY, reactions, replies, typing, read markers, redaction, and multiline.
/secure
Privacy & security
TLS with CertFP client certificates, SASL, and SOCKS5 / HTTP-CONNECT proxies with remote DNS so your lookups never leak.
/bouncer
Works with bouncers
ZNC, soju, and others — replay stored history on reconnect and pick conversations back up where you left off.
/transfer
DCC file transfers
Send, receive, and chat over DCC — passive mode, resume, and automatic port mapping through your router.
/scriptable
Automate with JS
Hook commands and incoming messages with a sandboxed JavaScript API.
/about
Built with Apple frameworks only.
No third-party dependencies that need to be kept updated. I take great care to keep the codebase secure and robust.
I may open source the project in the future. For now, though, I'm a sole developer with this as a side project, and I don't have the time to manage pull requests and issues the way a good open source maintainer should.
— /fb
Get on a network in a minute.
Add a server, pick a nick, connect. bIRC remembers the rest.
