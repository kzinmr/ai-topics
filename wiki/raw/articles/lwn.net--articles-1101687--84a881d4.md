# Critical PHP security update coming

Source: https://lwn.net/Articles/1101687/

The PHP security team has [let it be known](https://www.php.net/archive/2026.php#2026-10-20-1) that there is a high-stakes security update coming at 14:00 UTC on October 21. "All PHP users are encouraged to prepare now so they can upgrade as soon as the release is available". Anybody running a PHP site probably needs to be prepared for this one.

(Notable comment: someone reportedly ran AI tools against PHP and publicly disclosed the vulnerability ahead of the embargo, producing a PoC before a patch exists — https://jackalsyn.com/posts/php-up-2026.html)
