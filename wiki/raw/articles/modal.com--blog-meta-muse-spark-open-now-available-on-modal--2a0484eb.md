# Muse Spark Open is now available on Modal

Source: https://modal.com/blog/meta-muse-spark-open-now-available-on-modal

Meta just released weights for Muse Spark Open, and it’s now available on Modal Auto Endpoints.
Muse Spark Open is built for agentic coding and long-horizon tasks, with native multimodal understanding and a 1M-token context window. It supports writing and debugging code, multi-step planning, sequential tool use, and failure recovery across extended workflows.
In Meta’s evaluations, Muse Spark Open scores 76.4 on Terminal-Bench 2.1 using the Terminus 2 agent and 60 on DeepSWE 1.1 using Meta’s preferred harness, with xhigh reasoning effort. See the
released model card
for the benchmark results and evaluation settings.
Muse Spark Open runs on Modal as a
Shared Endpoint
with per-token billing.
