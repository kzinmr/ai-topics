# Linear Coding Sessions

- Source: https://linear.app/coding-sessions
- Scraped 2026-11-03 (page meta + rendered copy).
- Surfaced on X by Karri Saarinen (@karrisaarinen, Linear CEO), 2026-11-03, replying to a user complaint that Linear-launched Codex agents broke after OpenAI's "new Codex Cloud experience" change: "try Linear coding session (you can use it with codex). Linear sets up environments and works lot faster".

## What it is

"Linear Agent can now write code. Triage, plan, build, and review all in one place." — coding sessions where you assign issues to Linear itself and get back a reviewable diff / draft PR.

## Key features (from the product page)

- **Frontier models via coding harnesses**: sessions are powered by **Claude Code and Codex**, configured at the workspace level. (Demo page shows "Linear Opus 5.5" running a session: worked 32s, pushed and opened a draft PR with per-file diffs.)
- **Start from anywhere**: kick off a coding session from an issue, a chat, a comment, or a Slack thread; Linear gathers the relevant context.
- **Delegate or automate**: assign issues directly, or let Linear pick them up the moment they land in Triage — "Bugs can be investigated and fixed before anyone touches a keyboard."
- **Cloud sandboxes**: every session runs in a secure cloud sandbox; no local setup, no babysitting. Then review the diff, ask for changes, or merge.
- **Full workspace context**: Linear natively understands issues, projects, documents, discussions, and customer requests.
- **Multiplayer sessions**: collaborative by default — follow progress, ask questions, steer the session while it runs, or iterate from the diff. Point the agent at a project and let it work from the spec.
- **End-to-end**: investigate, implement, review in one continuous workflow with no handoffs between tools.

## Context

Positions Linear as an agent-native issue tracker that owns the full loop (triage → plan → build → review), competing with GitHub's Copilot/coding-agent surface and with standalone coding agents. Karri's framing emphasizes that Linear sets up the environments itself and is faster than the Codex-in-Linear integration path.
