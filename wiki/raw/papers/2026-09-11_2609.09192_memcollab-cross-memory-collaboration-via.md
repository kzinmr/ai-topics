# MemCollab: Cross-Memory Collaboration via Test-Time Memory Evolution

**arXiv:** 2609.09192  |  **Link:** https://arxiv.org/abs/2609.09192

**Authors:** Shengguang Wu, Qinting Wu, Yuanhao Xiong, Wenkang Yang, Zhitao Yang, Honglin Gu, Yanshi Du, Yan Wang, Zhou Zhao, Lizhuang Ma, Fei Wu

## Abstract

Memory has emerged as a critical module for Large Language Model (LLM)-based agents, enabling them to learn from past experiences, yet its potential remains limited by being confined to single-agent contexts, resulting in inefficient knowledge transfer and homogenized experiences. We introduce MemCollab, the first cross-memory collaboration framework that enables multiple agents to share, negotiate, and refine their experiences at test time. MemCollab treats memories as living artifacts: when an agent encounters a new task, it retrieves memories from peers and evolves them through collaborative reasoning. We introduce a Cross-Memory Knowledge Graph (CrossMemKG) and a Test-Time Memory Evolution (TTME) mechanism that resolves conflicts between heterogeneous agent memories.
