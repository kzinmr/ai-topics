# A Privileged Teacher That Only Scores Cannot Search: Critique-Conditioned On-Policy Self-Distillation for Reasoning

**arXiv:** 2610.13744  
**Submitted:** 2026-10-09  
**Categories:** cs.AI, cs.CL, cs.LG  
**Comment:** Accepted as an oral at the FLLMPT workshop, NeurIPS 2026  

**Authors:** Mayug Maniparambil, Ayush Rai, Ekansh Verma, Noel E. O'Connor, Fergal Reid

## Abstract

On-policy self-distillation promises to replace the sparse outcome signal of verifiable-reward RL with dense token-level credit: a teacher conditioned on the reference solution scores the student's own rollout, and the resulting distributional shift is distilled back into the policy. We investigate whether this scoring signal actually contains corrective credit. Using gold error spans in student rollouts, we test the two signals consumed by self-distillation objectives, the full-distribution KL and the token log-ratio, for two properties: whether they localize errors and whether they push probability away from erroneous student tokens. They exhibit neither of these properties nor can they reliably distinguish correct from incorrect rollouts within the same problem. We argue that this failure is structural: locating an error in a reasoning trace is itself a search problem, while a scoring teacher is never explicitly asked to perform that search. The same model, with the same privileged information, localizes errors substantially better when allowed to generate a critique. This forms the motivation for \emph{critique-conditioned self-distillation}: first generate a critique of the current rollout, then condition the scoring teacher on that critique. The resulting signal localizes errors, is corrective within error spans, and shifts probability toward tokens that initiate backtracking such as ``Wait'', ``But'', and ``Actually''. We further show that the critique is useful both at test time, where resuming a wrong rollout with the critique in context converts math problems the model cannot solve by sampling, and in cold-start GRPO, where it provides an advantage signal on prompts for which verifiable rewards alone provide none.

 Abstract 

On-policy self-distillation promises to replace the sparse outcome signal of verifiable-reward RL with dense token-level credit: a teacher conditioned on the reference solution scores the student’s own rollout, and the resulting distributional shift is distilled back into the policy. We investigate whether this scoring signal actually contains corrective credit. Using gold error spans in student rollouts, we test the two signals consumed by self-distillation objectives, the full-distribution KL and the token log-ratio, for two properties: whether they localize errors and whether they push probability away from erroneous student tokens. They exhibit neither of these properties nor can they reliably distinguish correct from incorrect rollouts within the same problem. We argue that this failure is structural: locating an error in a reasoning trace is itself a search problem, while a scoring teacher is never explicitly asked to perform that search. The same model, with the same privileged information, localizes errors substantially better when allowed to generate a critique. This forms the motivation for critique-conditioned self-distillation : first generate a critique of the current rollout, then condition the scoring teacher on that critique. The resulting signal localizes errors, is corrective within error spans, and shifts probability toward tokens that initiate backtracking such as “Wait”, “But”, and “Actually”. We further show that the critique is useful both at test time, where resuming a wrong rollout with the critique in context converts math problems the model cannot solve by sampling, and in cold-start GRPO, where it provides an advantage signal on prompts for which verifiable rewards alone provide none. 

## 1 Introduction

Reinforcement learning with verifiable rewards (RLVR) provides a reliable but sparse learning signal: a reasoning rollout is correct or incorrect, but the verifier does not identify which intermediate decisions caused the outcome. In group-based objectives, the limitation is sharper when all sampled rollouts for a problem fail, since the relative advantage can vanish entirely. These all-wrong groups are precisely where additional supervision is most useful, yet outcome-based RL provides little guidance about how the reasoning should change. 

On-policy self-distillation (OPSD) offers a natural way to obtain denser supervision
 ( Zhao et al., 2026a ; Hübotter et al., 2026 ; Yang et al., 2026 ) .
The model generates a rollout as a student and then scores the same rollout as a teacher with privileged information, such as a reference solution. The discrepancy between the student and teacher distributions provides a signal at every token, even when the final answer is wrong. But density alone does not imply credit assignment. For the signal to be corrective, it should be larger where the reasoning goes wrong and should push probability away from the student’s erroneous choices. 

We test these properties directly on annotated error spans in logic and competition-mathematics rollouts. Across tasks and teacher scales, reference-conditioned scoring fails both tests: its distributional shift is only weakly concentrated at errors, its token-level signal does not reliably suppress erroneous student tokens, and even when aggregated over the full trajectory it does not distinguish correct from incorrect rollouts of the same problem. The limitation is therefore not in how a particular loss consumes the signal. Scoring itself exposes little information about where the reasoning failed. 

We argue that locating an error is itself a reasoning problem. A scoring teacher is given the reference but is never explicitly asked to compare it against the rollout and search for the mistake. When the same model is instead allowed to generate a critique, it can localize and explain the error. This motivates critique-conditioned self-distillation : first generate a localized critique of the student’s rollout, then condition the scoring teacher on that critique. Generation performs the search, and scoring converts the error it finds into a dense token-level signal. 

Our contributions are threefold. We show that the privileged teacher’s signal is neither localized nor corrective at gold error spans, and is not predictive of rollout correctness even at the whole-trace level (§ 5 ). We show that the failure lies in scoring, not in the information. The same model, given the same reference, localizes errors when it generates a critique (§ 6 ). Finally, we introduce critique-conditioned self-distillation , which uses generated critiques as privileged context for dense token-level supervision, and provide initial results using this signal for test-time inference and training (§ 8 , Appendix  A ). 

## 2 Related Work

 Privileged self-distillation. Our work sits between privileged self-distillation and error-localization methods. On-policy self-distillation uses a teacher conditioned on privileged information to provide dense token-level supervision over the student’s own rollout ( Zhao et al., 2026a ; Hübotter et al., 2026 ; Yang et al., 2026 ; Pan et al., 2026 ) . Recent work has identified several failure modes of this setup, including context-induced bias and weak or stylistic distributional shifts ( Harne et al., 2026 ; Kaur et al., 2026 ; Pan et al., 2026 ) . We differ by measuring the resulting signal directly at gold error spans and asking whether it carries corrective credit. 

 Locating errors is a reasoning problem. A separate line of work shows that locating reasoning errors can itself require generation or explicit reasoning, motivating generative verifiers, process supervision, and critique-based reward models ( Tyen et al., 2024 ; Zhang et al., 2025a ; Ankner et al., 2024 ; Khalifa et al., 2025 ) . Extended related work appears in Appendix  C . 

## 3 Preliminaries

## 3.1 Group-relative RL and the all-wrong group

For a prompt the policy samples a group of rollouts

rollout receives the group-normalised advantage

model’s competence—the ones it cannot yet solve once in tries—and they
are the reason verifiable-reward RL tends to sharpen what the base model can
already do rather than extend it ( Yue et al., 2025 ) .

## 4 Setup

## 4.1 Models, data, and labels

## Models and tasks.

We conduct the token credit signal analysis on the Qwen3-1.7B
 ( Yang et al., 2025 ) , Olmo-3-7B-Think and Olmo-3-32B-Think
 ( Olmo et al., 2026 ) rollouts. In each case the teacher is the same model with
privileged context, the on-policy self-distillation setting. For Qwen3-1.7B we
also run Qwen3-8B as a scale-control teacher. The tasks are Knights & Knaves
logic puzzles ( Xie et al., 2025a ; Xie et al., 2025b ) 
(K&K, 4–8 people) and DeepMath
 ( He et al., 2025b ) at two difficulty
bands (L5-7, L7-10). 

## Rollouts, references, and gold error spans.

We study wrong rollouts: verifier-incorrect, not truncated, and ending in a
boxed answer. We keep the verifier-correct rollouts of the same problems for
the correctness test in § 5 . The privileged reference is a
verified step-by-step derivation for K&K and the dataset’s reference solution
plus answer for DeepMath. We obtain gold error spans from a grader model that
reads the problem, the rollout and the reference and flags each error as a
verbatim quote of one sentence plus a reason. The grader is a DeepSeek model
 ( DeepSeek-AI et al., 2026a ; DeepSeek-AI et al., 2026b ) 
for the Qwen rollouts and claude-sonnet-5 ( Anthropic, 2026 ) for the Olmo-3 rollouts. We then have
gpt-5.2 ( OpenAI, 2025a ) and claude-sonnet-5 judge every flag independently, and we count a
flag as gold when both accept it. To measure how lenient the judges are, we
replace a quarter of the flags sent to each judge with position-matched
control sentences carrying the same reason and report their acceptance rate
with each study (Appendix  D ). We also perform the same signal
analysis on human-annotated error spans from ProcessBench (Appendix  J ). 

## Critics.

We use three critics to write the critiques of § 3.3 .
All use the same prompt: the rollout is presented sentence-numbered, each error
is a verbatim quote plus a reason, and recall is favoured over precision
(Appendix  D.1 ). All receive the same reference that
the teacher receives in the reference condition. We use gpt-5.2 as the oracle critic.
We also test whether the student can identify its own errors by having Qwen3-1.7B critique its own rollouts. We call this the self-critique. To assess whether a larger critic is more effective, we have Qwen3-8B perform the critiques as well. Appendix  B shows an oracle critique and a self-critique of the same rollout on each task.
Because critic and teacher see the same information, the comparison in
§ 6 is between generating and scoring, not between amounts of
information. The Olmo-3 models each critique their own rollouts
(Table  1 , Appendix  I ). 

## 4.2 The error-span Z readout

Per-token signals vary substantially across positions and rollouts, so we normalise each rollout against its own clean regions, following baseline-normalisation conventions in event-related neurophysiology ( Mercier et al., 2022 ) . For each rollout, we measure the signal in a short window immediately after the first gold error span and compare it with length-matched windows after clean spans in the prefix. We use the first error only because the reasoning after it is often wrong in ways the gold spans do not mark. If denotes the mean signal in window , we define

which we call the error-span Z . It measures how far the signal at the error departs from the rollout’s own baseline, in units comparable across signals, teachers, and tasks. 

A positive localization score means that the teacher’s distribution changes more at the error than at clean regions while a negative correction score means that privileged context lowers the probability of the student’s erroneous token. For localization, we log-transform the window-mean KL before computing to reduce the effect of its heavy tail. We report the mean across rollouts, calibrated by subtracting the score obtained when a random clean sentence from the same rollout is treated as the error. Thus, a signal with no error-specific content is centered at zero. Window sizes and other implementation details are given in Appendix  D .

## Not localized at the errors.

On K&K, error and control traces are nearly indistinguishable for both localization and correction. On DeepMath, the reference induces a small error-specific shift, most visible near the sentence boundary, but the effect is much weaker than under critique conditioning (Figure  3 ). Thus, the reference does affect the teacher’s distribution, but not selectively at the student’s errors. 

Table  1 shows the same comparison at the rollout level. Across students, tasks, and both signals, reference-conditioned scores remain close to the rollout’s clean baseline, and no setting satisfies the corrective criterion. When the reference signal does depart from zero, it can even point in the wrong direction: on L7-10, the Qwen teacher assigns more probability to the student’s erroneous token when conditioned on the reference. Increasing teacher capacity does not rescue the signal. Re-scoring the same Qwen rollouts with the 8B teacher leaves the reference-conditioned scores similarly small, while critique-conditioned signals become stronger across settings (Appendix  E ).

## Not even informative about correctness.

A diffuse signal could still be useful even if it does not localize errors, but at minimum it should recover the verifier’s one bit: whether the rollout is correct. We therefore test whether the localization or correction signal averaged over all tokens of a rollout ranks correct rollouts above incorrect siblings of the same problem. Across all three tasks and both teacher scales, neither reference-conditioned signal does so reliably: all twelve within-problem AUC confidence intervals include chance. Pooled across problems, some cells move away from chance (Figure  2 ), but the same deviations appear under content-free controls, indicating that they largely reflect problem-level factors such as length and difficulty. A trained probe over richer trace-level summaries does no better than the content-free controls (Appendix  G ). The reference-conditioned signal is therefore not only poorly localized. Even aggregated over the full trajectory, it carries little information about whether the reasoning is correct.

## 6 Dense Feedback Is a Search Problem

Why does the reference as privileged context induce so little signal at the error? We posit that locating where a rollout goes wrong, and why, is itself a reasoning problem: the reference and rollout must be compared until the discrepancy is found. A scoring pass is never asked to perform that search. It only produces a next-token distribution with the reference in context. If the failure is one of scoring rather than of information, the same model should recover the errors when allowed to generate. We test this directly by asking critics of different scales to read the problem, reference, and rollout and produce a list of errors, each with a verbatim quote and an explanation (§ 3.3 ). The quote makes the prediction directly localizable against the gold error spans and later provides an anchor for critique-conditioned teacher scoring. 

Table  2 confirms this prediction. The strongest critic localizes a gold error on well over half of the rollouts across tasks, while smaller critics succeed less often but preserve the same ordering with scale. Their main failures are practical rather than conceptual: they often paraphrase instead of quoting the rollout or violate the required output format. The key result is that the same reference that yields little error-specific signal under scoring produces explicit error locations under generation. This suggests that search is the missing computation. The next section asks whether these generated critiques can in turn be converted back into a dense signal by scoring.

## 7 Critique-Conditioned Self-Distillation Delivers

We replace the reference in the teacher’s context with a generated critique and score the student’s rollout exactly as before, using a critique from another problem as the placebo. Figure  3 repeats Figure  1 with the critique in place of the reference. The teacher, alignment, and estimand are the same. Under critique conditioning, the previously overlapping error and control traces separate. The teacher’s distribution shifts after the flagged error sentence, and its probability on the student’s continuation decreases there rather than elsewhere. This pattern holds across tasks. 

Table  1 confirms the same result at the rollout level. With oracle critiques, every setting satisfies the corrective criterion of § 5 on both signals: errors are localized relative to clean regions, and probability is pulled away from the student’s erroneous continuation, at several times the magnitude of the reference-conditioned signal. The critic sees only the reference that the scoring teacher already has. The critique therefore carries the same information in a form the scoring pass can use. Self-generated critiques preserve the same effect at reduced magnitude: with Qwen3-1.7B critiquing its own rollouts, localization is positive and correction is negative on all three tasks, and the effect strengthens with model scale. The weaker self-critique signal still trains. In the training runs of Appendix  A , the self-critique arm recovers most of the oracle-critique arm’s gain over GRPO (Table  6 ). Larger scoring teachers likewise amplify the critique-conditioned signal while leaving the reference-conditioned signal near baseline (Appendix  E ). Critique conditioning also recovers the trace-level correctness signal absent under the reference (Figure  2 ). The same pattern holds on human-labelled error steps: on ProcessBench ( Zheng et al., 2025 ) , with each solution scored by the Qwen2.5 model that wrote it, the reference is neither localized nor corrective, while a critique localizes the labelled step for both generators and corrects once the tokens it quotes are excluded (Appendix  J ).

## Correction resolves into self-correction language.

The correction signal in Table  1 shows that critique conditioning moves probability mass away from the student’s continuation, but not where that mass goes. We therefore inspect high-content tokens in the post-error window and bucket the teacher’s argmax prediction by destination. Under reference conditioning, error windows show no excess of self-correction markers such as Wait , But , or However while under critique conditioning, the reconsideration bucket rises to two to three times the control rate on every task (Table  4 ). Thus, the probability mass released from the student’s erroneous continuation is redirected toward self-correction language only when the teacher is told what is wrong, not merely shown the correct solution.

## Delivery decomposes into pointing and correcting.

A critique contains two separable components: a quote that points to the erroneous step, and a reason that explains why it is wrong. Table  4 ablates each in turn. Localization is carried primarily by the quote: removing the reason leaves it largely unchanged, while removing the quote weakens it across tasks. Correction depends on the reason: without it, the corrective shift shrinks substantially and, with the larger teacher, can disappear or even reverse. The two components therefore play distinct roles in delivery: the quote tells the scoring teacher where to react, while the reason tells it how to change the student’s distribution. 

## 8 Using the Signal at Test Time

We test whether the critique is useful at inference. We take wrong rollouts of
Olmo-3-32B-Think on L7-10, 55 rollouts from 39 problems, 19 of which the model
does not solve in eight samples. The model critiques each rollout with the
reference solution in context, the self-critique setting of
Table  1 . We cut the rollout at the first sentence the critique
flags and let the model continue from the cut, eight samples per rollout. The
critique item is placed at the cut together with the cue “Wait, I should
correct this reasoning.” The control cuts at a fixed depth and places the cue
alone. Table  5 reports sample accuracy. With the critique in
context the model solves the problems it never solved by sampling about twice
as often as the control. The critic had the reference in context, so the gain
measures what a privileged critique delivers at inference, not unaided
self-correction. We also train with the signal (Appendix  A ).

## 9 Conclusion and Limitations

We show that reference-conditioned self-distillation provides dense supervision but not reliable corrective credit: its signal does not localize student errors and is not informative about rollout correctness. The same teacher can recover those errors when allowed to generate a critique, suggesting that credit assignment requires an explicit search over the reasoning trace. Critique-conditioned self-distillation separates that search from scoring, using generation to identify the error and a scoring pass to turn it into dense token-level supervision. Limitations. Our study has three main limitations. First, our training evidence is small in scale, a 320-puzzle set and 100 steps (Appendix  A.2 ), and we have not run critique-conditioned self-distillation at full RL scale. Second, critique conditioning adds a generation pass over the wrong rollouts of each batch. In our runs this costs 6% of step time with the student as critic and about a fifth with an API critic (Appendix  A.3 ). Third, every critique in this paper, in the signal analysis, at test time and in training, is written with the reference solution in context. Our results show that a critique conveys privileged information in a form the scoring teacher can use, not that the model corrects itself unaided.

## Appendix A Training with the Critique-Conditioned Signal

We report two training experiments. The first is a cold-start pilot on four puzzles with Olmo-3-7B-Think, the pilot referred to in § 8 . The second compares the critique-conditioned term against GRPO and reference-conditioned self-distillation over 100 steps on Olmo-3-7B-Instruct, with the oracle critic and with the student as its own critic. We then report the compute cost of the critique pass. 

## A.1 Cold-start pilot on four puzzles

We train Olmo-3-7B-Think on four 16-person Knights & Knaves puzzles it never
solves in 64 samples. The student writes the rollouts, critiques its own wrong
rollouts with the verified derivation as reference, and scores them as its own
teacher. On all-wrong groups, where GRPO has no gradient, the critique-conditioned
correction signal in the critic-located error span becomes the advantage, with a
zero-sum positive term on the prefix before the error. The control is GRPO alone.
Both arms run 30 steps of 32 rollouts with one seed.

## A.3 Compute cost of the critique pass

Critique conditioning adds one generation per critiqued rollout. Only wrong rollouts in groups with at least one correct rollout are critiqued, 16 to 18 of the 128 rollouts per step in the runs of Table  6 . Table  7 gives the cost per step averaged over the 100 steps. The self-critique runs in the same inference engine as the rollouts. We push the frozen base weights, generate the critiques and push the current policy back. Olmo-3-7B-Instruct writes short critiques, 175 tokens on average, so the critique tokens are 0.4% of the rollout tokens generated per step and the whole pass is 6% of step time, one point of which is the weight swap. The API critic is a reasoning model and returns about 3,000 tokens per critique including its reasoning. Its share of step time is time spent waiting on the API, not GPU time, and could overlap with rollout generation.

## Knights & Knaves.

 Problem. A very special island is inhabited only by knights and knaves. Knights always tell the truth, and knaves always lie. You meet 6 inhabitants on this island: Yara, Liam, Peter, Sophia, Noah, and Bob. Yara says: “Peter is a knave if and only if Liam is a knight.” Liam says: “It is not the case that Yara is a knave if and only if Yara is a knight.” Peter says: “Bob is a knight.” Sophia says: “Liam is a knight.” Noah says: “It is not the case that Liam is a knave.” Bob says: “Noah is a knave.” 

 Reference answer. Yara is a knight, Liam is a knight, Peter is a knave, Sophia is a knight, Noah is a knight, Bob is a knave. 

 Student’s answer. Yara is a knight, Liam is a knave, Peter is a knight, Sophia is a knave, Noah is a knave, Bob is a knight. 

 Rollout excerpt. […] if Yara is a knight ( is true), then the statement “Yara is a knave if and only if Yara is a knight” would be “False True”, which is False. Similarly, if Yara is a knave ( is false), then the statement is “True False”, which is also False. Therefore, the statement is always false. Therefore, Liam’s statement is false. Therefore, if Liam is a knight, he would be making a false statement, which is impossible. Therefore, Liam must be a knave. Wait, that seems important. […] 

 Gold error. Liam’s statement is the negation of the inner biconditional, and since that inner biconditional is always false, Liam’s statement is actually true. 

 Oracle critique (gpt-5.2). 
ERROR 1: “Therefore, the statement is always false.” – The biconditional “Yara is a knave iff Yara is a knight” is always false, so its negation (Liam’s statement) is always true, not false. 

 ERROR 2: “Therefore, Liam must be a knave.” – Since Liam’s statement is necessarily true, Liam must be a knight, not a knave. 

 ERROR 3: “Since we just determined that Liam is a knave,” – This propagates the earlier incorrect classification of Liam, making subsequent deductions unreliable. 

 Self-critique (Qwen3-1.7B). 
ERROR 1: “Liam is a knave” – Liam’s statement is a contradiction (always false), so he must be a knave. This is correct, but the final answer contradicts this conclusion. 

 ERROR 2: “Noah is a knave” – Noah’s statement is “Liam is a knight,” which is false because Liam is a knave. Therefore, Noah is a knave. This is correct. 

 ERROR 3: “Bob is a knight” – Bob’s statement “Noah is a knave” is true, so Bob is a knight. This is correct. 

 ERROR 4: “Peter is a knight” – Peter’s statement “Bob is a knight” is true, so Peter is a knight. This is correct. 

 ERROR 5: “Yara is a knight” – Yara’s statement is true, so she is a knight. This is correct. 

 Final Answer (boxed): Yara is a knight, Liam is a knight, Peter is a knave, Sophia is a knight, Noah is a knight, Bob is a knave.

The oracle quotes the sentence before the gold error and the conclusion drawn from it, and each reason says which way to correct it. The self-critique quotes fragments of the final answer, endorses the student’s reasoning, and then writes the reference answer as its own final answer. Its quotes carry no location and its reasons carry no correction before that last line.
