# When Memory Burns: Threats and Controls in Persistent Memory of Autonomous LLM Agents

**arXiv:** 2608.22797  |  **Link:** https://arxiv.org/abs/2608.22797

**Authors:** Ce-Hao Su, Chun-Yu Wang, Shih-Kai Liao, Hong-Han Shuai, Ching-Chun Huang, Yen-Chun Chen

## Abstract

Persistent memory is emerging as a core component of autonomous agents. It lets them learn from experience, but it also expands their attack surface: memory content can be injected into memory, persisted, and later retrieved to influence behavior. We study this threat with a three-stage framework (injection, storage, retrieval). Across three agent frameworks, four attack strategies, three adversarial datasets, and nine attack targets, we find the vulnerability to be widespread and framework-agnostic. We introduce a memory control surface (MCS) with six controls: memory provenance, retrieval-time validation, context isolation, memory lifecycle management, memory access control, and behavioral guardrails, and evaluate each in isolation and combination.
