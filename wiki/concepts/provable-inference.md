# Provable Inference (Model Attestation)

Anthropic's 2026-11-04 research progress report on **provable inference**: cryptographic attestation that a response was generated by the specific model weights the user selected. Motivating gap: "When a user sends a request to an AI model, today they have no way of knowing for certain that the model they selected is the one that generated the response." HN: 238 pts ([item 50368626](https://news.ycombinator.com/item?id=50368626)).

## Technical shape (as reported)

- The provider commits to a set of weights; for open-weight models the commitment + seed are published so anyone can recompute it from the Hugging Face files and verify the exact checkpoint **and quantization** claimed (demonstrated on a Maverick demo).
- An integer/fixed-point inference path is proven equivalent to floating-point inference within a small error bound (non-adversarial prompts only; non-determinism of FP math tolerated within the bound).
- Current limits: greedy decoding, short contexts, ~**90–100× compute overhead**.

## What it defends against

1. **Silent model substitution** — a host serving a cheaper/quantized model while billing for a flagship one (the single most-cited grievance: OpenRouter-style routing, unannounced quantization, and Anthropic's own June 2026 "silently routing ML requests to an inferior model" controversy).
2. **Man-in-the-middle token streams** through the growing layer of content-level proxies between client and API.
3. **Hardware drift validation** — proving a deployment reproduces reference outputs across heterogeneous accelerators.

## Critiques

- **Wrong-property concern:** attestation proves *which* model ran, not that the answer is correct or that data wasn't exfiltrated (ajb); "if you don't trust the provider, game over anyway" (grey-area).
- **Cost:** for open weights, sampling four independent providers on the same non-batched prompt yields a probabilistic proof far cheaper than 90–100× zk-style overhead (vessenes).
- **Conflict of interest:** customers want output correctness; Anthropic wants proof-of-Anthropic-ness — "the end goal is FUD for cheaper model routing, which is at odds with their biz model" (pxmpxm). The irony of a company previously accused of silent routing leading model-provenance PR was widely noted.

## Significance

First serious production-track mechanism for **model provenance at inference time**, complementing weight-provenance work at training time (supply-chain lineage, cf. [[concepts/artifact-provenance-gates]]). If overhead falls, expect it to become table stakes for regulated workloads and a differentiator against router/aggregator ecosystems where model substitution is cheap.
