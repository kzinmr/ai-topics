# Open LLMs

> **Disambiguation / redirect.** The slug `open-llms` most precisely refers to **Eugene Yan's GitHub repository [`eugeneyan/open-llms`](https://github.com/eugeneyan/open-llms)** — a curated, frequently cited table of open-source / open-weight LLMs filtered specifically for **commercial usability** (permissive licenses, release notes, dataset provenance). See [[entities/eugene-yan]] for the author.

The repo tracks each model's parameters, context length, license, training tokens, and known usage — and became one of the go-to references (alongside `applied-ml` and `ml-surveys`) for engineering teams deciding whether an open model can be shipped in a product.

For the broader topic of open-source/open-weight language models as an ecosystem, see the canonical concept page:

- **[[concepts/open-source-llms]]** — open-weight models, licenses, economics, and the 2026 state of open-source AI.
