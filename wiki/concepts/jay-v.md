# Jay V

**Jay V** is a co-founder of **[[entities/opencode|OpenCode]]**, the
open-source, provider-agnostic AI coding agent launched on **June 19, 2025**
alongside [[entities/dax-raad|Dax Raad]] (public face / primary technical
voice), **Frank Wang**, and **Adam Elmore**.

## Role & Context

- Co-founded OpenCode as an open-source alternative to proprietary coding
  agents (notably Anthropic's Claude Code), motivated by the bet that
  proliferating AI coding models would demand a flexible, model-agnostic
  front-end.
- OpenCode's architecture: client-server split — backend handles LLM calls,
  tool execution, session management, orchestration; frontend is a TUI
  (rewritten in Zig + SolidJS for v1.0). Agents: Build (full tools) / Plan
  (read-only), plus General and Explore subagents.
- Dax Raad is the public spokesperson; Jay V's public footprint is smaller —
  the wiki currently sources his role from Grokipedia-sourced material on
  [[entities/dax-raad]].
