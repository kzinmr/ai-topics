# DeerFlow

> **Redirect**: The canonical page is [[concepts/deer-flow]].

**DeerFlow** (Deep Exploration and Efficient Research Flow) is ByteDance's open-source SuperAgent harness. This page held the earlier v1-era coverage and has been merged into the richer, newer [[concepts/deer-flow]] page (v2.0 ground-up rewrite).

## Unique facts preserved from this page

- **Full name**: Deep Exploration and Efficient Research Flow
- **License / traction**: MIT licensed, 67.5k+ GitHub stars
- **v2.0 rewrite**: no shared code with v1; backend (Python) + frontend (Node.js), Docker-deployable
- **Sandbox recommendation**: AIO Sandbox (Browser, Shell, File, MCP, VSCode Server in one container)
- **Skills**: progressively loaded, extensible via custom skill files
- **Multi-model**: Doubao-Seed-2.0-Code, DeepSeek v3.2, Kimi 2.5, OpenAI, Gemini
- **InfoQuest**: BytePlus intelligent search/crawling toolset integration
- **One-line bootstrap**: coding agents can install via `Install.md` with a single prompt
- **History**: Feb 28, 2026 — v2.0 claimed #1 on GitHub Trending; BytePlus/Volcengine cloud partnership; official site deerflow.tech
