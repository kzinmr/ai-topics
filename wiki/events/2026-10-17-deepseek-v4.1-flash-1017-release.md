# DeepSeek-V4.1-Flash-1017 + Search/Fetch API release (2026-10-17)

Announced 2026-10-17 08:35 UTC via a 4-post X thread and API docs news page. Two coupled announcements: (1) **DeepSeek-V4.1-Flash-1017**, an open-weight (MIT) refresh of [[entities/deepseek-v4.1-flash]] with large agentic-coding gains; (2) **Search & Fetch APIs opened to everyone** at $0.75 per 1,000 calls — DeepSeek moving from model provider to agent tooling infrastructure.

## Model: DeepSeek-V4.1-Flash-1017

- "Minor update" (their words) delivering large benchmark gains; DeepSeek frames it as a **Pareto improvement in performance and cost** — stronger benchmarks, faster task completion, *shorter outputs* than the previous version.
- **RL with self-feedback** improves end-to-end project development (game creation, 3D modeling). Marketed as "Wish-Driven Programming Made Real"; demos include a 3D Forbidden City model, a web racing game, a Godot Portal 2 recreation.
- Optimized for **DeepSeek Harness v0.2.1-rc.1**, **Tencent CodeBuddy**, **WorkBuddy** — the harness-coordinated release pattern (see [[concepts/deepseek-harness]]).
- Weights on Hugging Face / ModelScope, MIT license. 1M-token context; recommended `max_tokens ≥ 256K`. No Jinja chat template — ships a Python `encoding.py` reference plus `deepseek-recipe` (Rust + Python bindings) as the maintained prompt toolkit.

Profile: top of the compared field on agentic coding benchmarks (DeepSWE, Apex, Automation-Bench), beating GLM-5.3 and GPT-5.6 Sol and exceeding Opus 5 on several — unusual for a "flash"-tier model. Gains of +8 to +11 points over its own predecessor on Terminal-Bench/ProgramBench.

### Pricing

OpenRouter lists $0.15/M input, $0.60/M output, 1M context — **unchanged from V4.1-Flash**, so the benchmark gains come at the same price, and shorter outputs further reduce cost per task.

## Search & Fetch APIs

- Powered by DeepSeek's **in-house search engine** (they claim hundreds of millions of requests/day internally). Endpoints: `POST /v1/tools/search`, `POST /v1/tools/fetch`.
- **$0.75 per 1,000 calls** per endpoint — roughly an order of magnitude cheaper than OpenAI's web search tool (~$25/1k calls); comparable third-party options are Brave/Tavily Search APIs.
- Free via server-side tools in DeepSeek Harness, **Claude Code, and Codex** until **Oct 31, 2026, 16:00 UTC** — explicitly targeting agent-harness tool-call traffic.
- Returns structured JSON tuned for agents: `rerank_score` (0–3), `summary` (600–800 chars, "intended to be read by a model"), `authority` tier (0–4), and query operators (`site:`, `lang:`, `after:`/`before:`). Fetch returns pages as Markdown.

See [[concepts/agentic-search]] for the broader landscape of search-for-agents APIs this enters.

## Reception (first hours; HN 278pt/106c + 240pt/97c threads)

- Price/quality shock: "$20 of DeepSeek API spend gets far more done than a $20 OpenAI plan"; "at this rate the frontier labs will be Anthropic and DeepSeek."
- Benchmark skepticism is standard now: "Those benchmarks can't possibly be real, right?" — plus context that 110 reward hacks/grading bugs in Terminal-Bench/DeepSWE/BFCL had been reported days earlier (2026-10-14).
- Recurring multi-model workflow: plan with a frontier model (Opus), implement with DeepSeek/GLM flash, review with another — the flash tier now covers ~90% of tasks for many users.
- The "minor update... delivering substantial improvements" phrasing was widely mocked as engineer-written marketing.
- Local-run reality check: 552B MoE is large even for a flash model; consumer setups require aggressive quantization.

## Significance

1. **Open-weight cost frontier moved again**: flash-tier open weights beating GLM-5.3 and matching/exceeding closed frontier models on agentic coding, at $0.15/$0.60 per M tokens.
2. **Rapid checkpoint cadence as strategy**: V4.1-Flash (Sep 10) → 1017 (Oct 17) — small dated refreshes that keep pushing the performance–cost Pareto frontier between major versions.
3. **Vertical integration for agents**: in-house search + fetch APIs complete a model + harness + tools stack in one vendor; the free-until-Oct-31 window across Claude Code/Codex is direct competition for tool-call spend currently going to search API vendors.
4. All performance claims are vendor-self-reported; independent verification (Artificial Analysis, third-party harness runs) pending as of 2026-10-17.
