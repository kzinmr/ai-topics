# Greg Ceccarelli

Product and data-science leader in the developer-tools space: **chief product officer at Pluralsight**, later led **data science at GitHub**, and currently on the team at **SpecStory**.

## Agentic-development practice at SpecStory (Nov 2026)

Quoted by [[entities/hugo-bowne-anderson]] in *What Happens to the Org Chart When Agents Do the Work?* (Vanishing Gradients, 2026-11-25). Source: raw/articles/hugobowne.substack.com--p-what-the-amish-can-teach-us-about--5afbb1b68f99df90.md.

- **Agents outrun PR review → push straight to main.** At SpecStory, "their agents write code faster than the team can review pull requests, so they push changes straight to main and keep branches for experiments." This is the tight-aligned small human+agent team pattern where the pull request stops being the coordination surface. See [[concepts/code-review-bottleneck]], [[concepts/coding-agents/code-review-agents]].
- **Background PR security-review agent.** "A background agent that reviews pull requests already knows what to watch for and what to do" — a PR itself is the trigger for an agent to run a security review unprompted, no human having to ask each time. Cf. the PR-triggered background-agent org-chart pattern in [[concepts/ai-organization/ai-org-from-hierarchy-to-intelligence]].
