# Lovable

**Lovable** is a Swedish AI startup in the vibe-coding space, building products that let users create software by describing it in natural language. Its flagship product is Lovable Studio (formerly GPT Engineer), an AI app builder.

## Funding & Valuation timeline

| Date | Event |
|------|-------|
| Jul 2025 | Series A **$200M** — "fastest all-in-one software engineering platform to reach **$100M ARR**" (TechCrunch) |
| Aug 2025 | Accenture partnership announced |
| Feb 12, 2026 | Series B **$400M** at **$6.6B valuation**, led by **Menlo Ventures** (CNBC, Bloomberg) |
| Jul 2026 | **$400M ARR** reported — more than doubled since February (TechCrunch) |
| Aug 2026 | Raised **$400M** at a **$13.3B valuation** — double the $6.6B valuation from December 2025 (eight months). Co-led by **Menlo Ventures** and the EQT-managed **Scaleup Europe Fund**, with **Tencent** and **Balderton** joining. Revenue run rate heading for **$600M** annualized. |

## 2026 Product Trajectory (from changelog)

The 2026 arc repositions Lovable from "vibe coding app builder" to an **enterprise AI software workspace with autonomous agents**:

- **Jun 2026** — Skill Editor (AI-guided skill creation), Visual Edits (direct UI editing in preview), project/workspace cost limits & spend tracking.
- **Jul 2026** — Projects 2.0, agent profiles, agent rules (project/workspace/org levels), scheduled agent automations, background agent tasks from Slack, desktop app for Windows, audit logs, org security assessments.
- **Aug 2026** — **Workspaces** (org-level project/member/role grouping), custom user roles, background agents across projects, Devin/MCP connection to GitHub Cloud-hosted runners.
- **Sep 2026** — **Lovable 2.0** (Sep 17) — the launch post links to an **academic paper** introducing a new coding-agent benchmark; **Lovable Agents** (Sep 24) — an agentic layer where you assign roles to agents and the agent takes work "from idea to working software". SOC 2 Type II / GDPR / full SSO enterprise workspace.
- Integrations added: monday.com, ClickUp, Klaviyo, HeyGen, HubSpot Marketing, Microsoft Teams + Microsoft 365 suite, Azure Blob Storage.

## Significance

Lovable is one of the strongest signals for the [[concepts/ai-coding-tools|AI coding tools]] category: a vibe-coding startup whose valuation doubled in eight months while revenue run rate approached $600M. It is frequently cited alongside Cursor, Replit, and other [[concepts/ai-coding-workflows|AI coding]] players in analyses of the AI application-builder market, and appears in consolidation forecasts (e.g., [[entities/factory|Factory]]'s prediction that second-tier startups like Lovable and Magic would be acquired by hyperscalers by late 2026).
