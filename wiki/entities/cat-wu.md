# Cat Wu

Head of Product at Anthropic, responsible for Claude Code and Anthropic's product development strategy.

## Overview

Cat Wu leads product development at Anthropic with a focus on making the Anthropic product team move faster than any other comparable organization. She was featured in Lenny's Newsletter (April 23, 2026) discussing Anthropic's product methodology, development velocity, and the philosophy behind Claude Code's design.

## Role at Anthropic

- **Title:** Head of Product
- **Key Product:** Claude Code — Anthropic's AI coding agent
- **Focus:** Product development velocity, developer tooling, agent UX

## Key Insights from Lenny's Newsletter Interview

### Development Velocity Philosophy

Anthropic's product team operates at exceptional speed compared to industry peers. This velocity is achieved through:

1. **Clear ownership** — Product leads have decision autonomy
2. **Bias toward shipping** — Minimal bureaucracy, fast iteration cycles
3. **Developer-first mindset** — Claude Code designed by developers, for developers
4. **Tight feedback loops** — Rapid user testing and iteration

## Fireside Chat Insights (July 2026)

At the AI Engineer World's Fair (July 2026), Cat Wu joined [[entities/simon-willison|Simon Willison]]'s fireside chat with [[entities/thariq-shihipar|Thariq Shihipar]] (transcript published July 21). Key product insights:

- **Claude Tag lands 65% of the Claude Code team's product engineering PRs** — the internal version of Anthropic's Slack collaboration agent. Wu describes it as "the evolution of Claude Code" and a large shift in how Anthropic works.
- **Delegation shift**: with each model generation, the team delegates more menial implementation to Claude; with Fable they can "one-shot a ton of features."
- **Product taste over execution**: the idea-to-build timeline dropped from 6-12 months to as little as a week — engineers now need business sense and product taste more than execution skill.
- **Dogfooding + internal retention bar**: Anthropic ships features to employees first and only ships what demonstrates user retention ("the more brutal the feedback, the better"); a clear internal bar for active users/retention drives polish.
- **Remote control surprise**: the unexpectedly popular workflow is plugging in a laptop at night, opening remote control sessions, and steering Claude Code from a phone on the couch.
- **Automated code review**: humans still review critical core changes, but Claude fully reviews "outer layers" after a 6+ month trust-building process with incident PRs added to an eval set.
- **Evals strategy**: an eval base enables new models to be drop-in replacements; behavioral evals catch UX friction (e.g., "people really don't like it when Claude Code says it's time to go to sleep").
- **Auto mode trust**: "almost every single person" at Anthropic uses auto mode; heavily red-teamed, with published evals planned.
- **UX taste as frontier gap**: Wu still doesn't rate Claude's design/UX taste — "the paddings might be off" — and wants future models as "interaction design thought partners."
- **Personal build**: a rock-climbing app + workflows-powered trip research ("vibe coding Jira for mountain climbing").
